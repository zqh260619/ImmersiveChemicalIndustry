## 1. 设计定位：本阶段要教的六个"终身技能"

1. **电网与电力拖动**——汽轮机、交流发电机、变压器、电动机；工厂从"一台蒸汽机带一根天轴"变成"每个设备一台电机"。
2. **电解的两条路**——水溶液电解（氯碱、精铜）与熔盐电解（铝、钠）；槽压、电流效率、法拉第定律。
3. **深冷与精馏**——压缩-冷却-节流膨胀（焦耳-汤姆逊）、双塔精馏、氧氮氩分离；"把空气变成三种气体"。
4. **电炉与合金**——电弧炉（石墨电极，2000–3000 °C）、不锈钢、钨粉冶金/硬质合金。
5. **卤素化学与耐蚀材料**——HF/F₂ 是最难伺候的化学品，逼出镍合金、PTFE、Nafion 膜。
6. **规模工程与联产**——转炉、回转窑、造纸、氯碱联产：装置之间必须物料平衡。

## 2. 开局与世界生成

### 2.1 出生点保障

阶段 5 的工业区保证：

- **铝土矿**（红土型，三水铝石/一水硬铝石）、**铬铁矿**、**镍矿**（红土镍/硫化镍）、**钼矿**（辉钼矿）；
- **钨矿**（黑钨矿/白钨矿）、**萤石**（CaF₂）、**石墨**、**石灰石/黏土/页岩**（水泥）；
- 岩盐（氯碱）、煤/黄铁矿（电力与硫酸）、河流（水电/冷却）。

### 2.2 原版内容调整（本阶段生效范围）

- 电力为交流系统（电压/频率/相位），变压器、电动机、输电线；
- 红石系保持移除；控制仍走仪表/继电器/手动；
- 高压电有触电风险；电缆需绝缘（橡胶/纸/油）；
- 液氮/液氧/氩为流体（低温容器）；空分产品不能"常温常压随便装"。

### 2.3 气候与季节

- 水电受枯水期影响；火电（煤）稳定但污染；
- 空分冷箱需要干燥空气，湿度影响分子筛负荷；
- 水泥/造纸耗水，厂址靠近水源。

## 3. 核心机制

### 3.1 电网

- 汽轮机（帕森斯 1884，多级叶轮）+ 交流发电机（50 Hz/3000 rpm 或 60 Hz/3600 rpm）；
- 变压器（硅钢片铁芯）升压输电、降压用电；铜/铝导线；
- 电动机驱动泵、压缩机、搅拌、行车、磨机——工厂布局不再受天轴限制；
- 电压等级：低压（380 V）/高压（6–10 kV）；绝缘与触电风险。

### 3.2 电解

| 类型 | 例 | 槽压 | 关键 |
|---|---|---|---|
| 水溶液 | 氯碱、电解精铜、电解水 | 2–4 V | 离子膜/隔膜、电流效率 95–97% |
| 熔盐 | 电解铝（冰晶石-氧化铝）、电解钠（NaCl-CaCl₂） | 4–5 V（铝） | 960 °C、碳阳极消耗、电流效率 93–96% |

- 法拉第定律：电量 ↔ 物质量；槽压 × 电流 = 功率；
- 氯碱理论分解电压 ~2.19 V，工业槽 3.0–3.5 V（过电位 + 欧姆损失）。

### 3.3 深冷与空分

- 空气压缩（5–6 bar）→ 冷却 → 分子筛干燥/脱 CO₂ → 主换热器 → 节流膨胀（焦耳-汤姆逊）→ 液化；
- 双塔精馏：高压塔（~5–6 bar）与低压塔（~1.3 bar）耦合；氮（77 K）从塔顶、氧（90 K）从塔底、氩（87 K）侧线；
- 产品：O₂ 99.5%（转炉/接触法/医疗）、N₂ 99.999%（惰性气氛）、Ar 99.999%（焊接/色谱/灯泡）；
- 绝热：珠光砂/真空夹层；冷箱内碳氢富集是真实爆炸风险（需前置吸附）。

### 3.4 电炉与合金

- 电弧炉：石墨电极 + 三相交流，2000–3000 °C；炼钢（废钢/生铁）、电石（CaO + 3C → CaC₂ + CO，2000–2200 °C）、黄磷（阶段 7）、冶金硅；
- 不锈钢：304（18Cr-8Ni）、316L（16–18Cr-10–14Ni-2–3Mo），Cr₂O₃ 钝化膜；
- 钨粉冶金：黑钨矿 → 仲钨酸铵 → WO₃ → H₂ 还原（700–900 °C）→ 钨粉 → 压制烧结（~2000 °C）→ 拉丝（灯丝）/硬质合金 WC-Co。

### 3.5 转炉炼钢（BOF）

- 1952 年林茨-多纳维茨工艺：氧气顶吹（O₂ 99.5%），30–40 min 一炉；
- 造渣（石灰）→ 脱碳/脱磷/脱硫；渣碱度 CaO/SiO₂ 2.5–3.5；终点碳 0.05–0.1%；
- 煤气回收（CO）与余热锅炉。

### 3.6 卤素化学与耐蚀材料

- HF：萤石 + 浓硫酸，200–250 °C → CaSO₄ + 2HF↑；HF 腐蚀玻璃/硅酸盐，必须用铅/镍合金/PTFE；
- F₂：电解 KF·2HF（90–100 °C）→ F₂；最活泼非金属，镍/蒙乃尔容器；
- PTFE：四氟乙烯聚合（1938）→ 耐一切酸、260 °C，"塑料王"衬里；
- Nafion：全氟磺酸膜（1960s）→ 离子膜法氯碱的核心。

### 3.7 联产平衡（氯碱）

- 2NaCl + 2H₂O → Cl₂↑ + H₂↑ + 2NaOH；
- 摩尔比 1:1:2；Cl₂ 与 H₂ 必须同时消化（否则放空/爆炸风险），NaOH 必须有去处；
- H₂ → 合成氨/加氢；Cl₂ → 盐酸/PVC/氯化；NaOH → 造纸/氧化铝/皂化。

### 3.8 安全

- Cl₂/HF/F₂ 中毒与灼伤；正压呼吸器、洗眼器、葡萄糖酸钙（HF）；
- 高压电、电弧光（紫外线）、深冷烫伤（液氮/液氧）；
- 空分碳氢爆炸、氧气管道禁油。

## 5. 工艺链详细设计

### 5.1 汽轮机与交流电网（6–10 h）

锅炉（阶段 4）→ 过热蒸汽 → 汽轮机（多级叶轮）→ 交流发电机 → 变压器 → 输电；电动机替换天轴；电网频率/电压稳定（调速器 + 励磁）；高压安全。

### 5.2 电弧炉与不锈钢（6–8 h）

电弧炉（石墨电极）→ 废钢/生铁 + 铬铁/镍铁 → 熔炼 → 成分调整（Cr/Ni/Mo）→ 出钢 → 轧制/锻造；不锈钢耐蚀测试（盐酸/氯离子浸泡）；316L 用于后续氯碱/氟化学设备。

### 5.3 钨粉冶金（5–7 h）

黑钨矿 → 碱煮/酸分解 → 仲钨酸铵 → 煅烧 WO₃ → H₂ 还原 700–900 °C → 钨粉 → 压制/烧结 ~2000 °C → 钨条 → 拉丝（灯丝）/WC-Co 硬质合金（刀具/模具）。

### 5.4 氯碱（8–12 h）

原盐溶解 → 盐水精制（NaOH/Na₂CO₃ 除 Ca/Mg，离子交换）→ 隔膜电解（石棉/改性隔膜）→ Cl₂/H₂/NaOH（32%）→ 升级离子膜法（Nafion）：槽压更低、碱更纯、无石棉/汞污染；尾气碱吸收；H₂ 纯化。

### 5.5 氟化学（6–10 h）

萤石 + 硫酸 → HF（铅/镍设备）→ 电解 KF·2HF → F₂（镍/蒙乃尔）→ PTFE（四氟乙烯聚合）/Nafion（全氟磺酸膜）；HF 用于蚀刻玻璃（阶段 8 电子级）；安全：HF 灼伤用葡萄糖酸钙。

### 5.6 拜耳法 + 电解铝（10–14 h）

铝土矿破碎 → NaOH 溶出（一水硬铝石 200–240 °C/高压；三水铝石 105–150 °C）→ 稀释/沉降（赤泥分离）→ 晶种分解 → Al(OH)₃ → 煅烧 1000–1200 °C → Al₂O₃；冰晶石（HF + Al(OH)₃ + Na₂CO₃ 合成）→ Hall-Héroult 电解（960 °C、4–4.5 V、13–15 kWh/kg Al、碳阳极消耗 0.4–0.45 kg/kg Al）→ 铝锭；赤泥堆存（环保）。

### 5.7 空分双塔（12–18 h，本阶段 Boss）

空气压缩（5–6 bar）→ 冷却/干燥（分子筛）→ 主换热器 → 节流膨胀 → 双塔精馏 → O₂/N₂/Ar；液氮/液氧储存（低温绝热）；纯度验证（O₂ 燃烧试验、N₂ 露点/氧分析、Ar 光谱? 简化）。

### 5.8 转炉炼钢（5–7 h）

高炉铁水 → 转炉（氧气顶吹）→ 造渣（石灰）→ 脱碳/脱磷/脱硫 → 出钢 → 铸锭/连铸；煤气回收（CO）→ 发电/燃料；钢种：低碳钢/中碳钢/合金钢。

### 5.9 水泥回转窑（5–7 h）

石灰石 + 黏土/页岩 → 生料粉磨 → 回转窑 1450 °C → 熟料（C₃S 50–70%、C₂S 15–25%、C₃A 5–10%、C₄AF 5–15%）→ 加石膏粉磨 → 水泥；混凝土用于大型基建（厂房/储罐/大坝）。

### 5.10 造纸（5–7 h）

木材 → 削片 → 硫酸盐法蒸煮（NaOH + Na₂S，160–170 °C，1–2 h）→ 洗涤 → 漂白（Cl₂ → ClO₂ 环保升级）→ 打浆/抄纸 → 纸张；黑液回收（碱回收炉）——联产/环保第一课。

### 5.11 电石/乙炔（4–6 h）

石灰 + 焦炭 → 电弧炉 2000–2200 °C → CaC₂ → 水解 → C₂H₂（氧炔焰焊接/切割）；乙炔是阶段 6 乙炔化学的入口。

## 7. 里程碑与阶段出口

**九项必需（研究手册逐条记录）：**

1. **交流电网**：汽轮机 + 发电机 + 变压器输电，电动机驱动一台设备；
2. **电弧炉不锈钢**：304 或 316L，耐蚀测试通过；
3. **钨丝/硬质合金**：拉丝成功、硬质合金刀具可用；
4. **氯碱**：隔膜法或离子膜法，Cl₂/H₂/NaOH 三产品达标，尾气吸收合格；
5. **HF/PTFE**：HF 制备 + PTFE 衬里（或 Nafion 膜）；
6. **电解铝**：拜耳法 Al₂O₃ + 冰晶石电解，铝锭产出，电耗核算；
7. **空分双塔**：稳定产出液氮/液氧/氩，纯度达标（**总门槛**）；
8. **转炉钢 + 水泥**：钢水成分合格、熟料矿物相（XRD 前身：目测/化学）合格；
9. **造纸全链**：纸浆—漂白—抄纸，产出研究手册用纸。

**出口任务「油的召唤」**：在地表找到油苗（黑色粘稠渗出）或沥青脉；用钢管 + 钻头钻第一口浅井，见到油气显示——研究手册解锁阶段 6："石油，是液态的碳骨架宝库。"

## 8. 挑战与事故清单

| 事故 | 触发 | 后果 |
|---|---|---|
| Cl₂ 泄漏 | 电解槽/管道/尾气失效 | 大范围中毒；正压呼吸器、碱液吸收 |
| HF 灼伤 | 萤石酸解、HF 输送 | 深层组织损伤；葡萄糖酸钙急救 |
| F₂ 泄漏 | 电解槽/镍设备失效 | 极端腐蚀/中毒；全封闭 |
| 电解铝电耗失控 | 槽压升高/阳极效应 | 成本爆炸、停产 |
| 空分碳氢爆炸 | 分子筛失效/乙炔积累 | 冷箱爆炸（真实事故） |
| 氧气管道着火 | 油脂污染 | 燃爆 |
| 高压触电/电弧光 | 电网/电弧炉 | 伤亡/电光性眼炎 |
| 液氮/液氧冻伤 | 低温容器泄漏 | 组织冻伤 |
| 赤泥/黑液污染 | 氧化铝/造纸废液 | 环保惩罚（阶段 6+ 立法） |

| 第 20–25 天 | 空分双塔（Boss） | 14–20 h |
| 第 26–28 天 | 转炉钢、水泥、造纸 | 10–14 h |
| 第 29–30 天 | 电石/乙炔、出口任务（油苗） | 4–6 h |

## 10. 实现要点（技术）

- **电网**：交流电压/频率/相位；变压器、电机、输电线损耗；触电/电弧事故；
- **电解槽**：槽压/电流/电流效率；隔膜→离子膜升级；气体纯度与尾气处理；
- **空分**：压缩-换热-节流-精馏的多级热力学模型；产品纯度；冷箱碳氢风险；
- **电炉**：电极消耗、弧光、炉衬寿命；功率-温度曲线；
- **转炉**：吹氧曲线、渣碱度、终点碳；煤气回收；
- **回转窑**：物料停留时间、温度带、熟料矿物相；
- **造纸**：蒸煮/洗涤/漂白/抄纸；黑液碱回收；
- **数据驱动**：槽压、电流效率、能耗、纯度阈值 JSON 化。
