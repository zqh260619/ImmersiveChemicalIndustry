## 1. 设计定位：本阶段要教的六个"终身技能"

1. **多步合成**——保护基正交、选择性酯化、汇聚式路线；每一步都要纯化与表征。
2. **天然产物提取**——红豆杉针叶 → 10-DAB（约 1 g/kg 鲜叶）；柱层析/结晶放大。
3. **不对称催化的真实应用**——Sharpless 双羟化/环氧化、Noyori 氢化、MacMillan 有机催化；ee 不是数字，是药效/毒性。
4. **表征验收**——HPLC/手性 HPLC/NMR/MS/旋光/熔点/XRD/活性实验；六项同时达标才算"做出来了"。
5. **稀土分离与高纯材料**——溶剂萃取级联（TBP/P507）、离子交换；单一稀土 99.99%+。
6. **极端条件与科研诚信**——高压（GPa）、低温（4.2 K）、数据复现 3 次、排除假象。

## 2. 开局与世界生成

### 2.1 出生点保障

阶段 9 的终局区保证：

- **红豆杉林**（温带/亚热带，针叶可反复采收；种植周期长）；
- **稀土矿**（独居石/氟碳铈矿，伴生钍——辐射防护）、**砷矿**（雄黄/雌黄/毒砂）、**重晶石**（BaCO₃）、**铜/镍/镧矿**；
- **金刚石**（金伯利岩筒，深部）或 HPHT 合成原料（石墨 + 触媒）；
- 液氦来源（天然气提氦 + 液化，阶段 5/6 的深冷技术延伸）。

### 2.2 原版内容调整（本阶段生效范围）

- 红豆杉为可种植作物（生长周期以游戏日计）；针叶采收不毁树；
- 高压设备（六面顶压机/金刚石对顶砧）为多方块；压力单位 GPa；
- 液氦/液氮为低温流体；杜瓦/冷屏；
- ¹³C 标记 CO₂ 为稀有物品（同位素分离，隐藏成就用）。

### 2.3 气候与季节

- 红豆杉生长慢（数年），需要提前规划种植园；
- 液氦持续蒸发，实验窗口有限（需提前备样）；
- 高压实验对温度/振动敏感，需恒温实验室。

## 3. 核心机制

### 3.1 紫杉醇路线（主线）

**半合成（商业化路线，推荐）**：

1. **10-DAB 提取**：红豆杉针叶干燥/粉碎 → 甲醇/乙醇浸提 → 浓缩 → 液液萃取 → 柱层析 → 结晶（10-DAB ≥95%）；
2. **侧链合成**（(2R,3S)-N-苯甲酰-3-苯基异丝氨酸）：
   - 苯甲醛 + 醋酐 → 肉桂酸（Perkin）→ 酯化；
   - **Sharpless 不对称双羟化**（AD-mix-β：K₂OsO₄ + (DHQD)₂PHAL）→ (2R,3S)-二醇（ee ≥95%）；或 Sharpless 环氧化 + 叠氮开环（安全替代：邻苯二甲酰亚胺 Gabriel）；
   - 胺化/苯甲酰化 → 侧链酸；或做成 β-内酰胺（Holton 路线）直接偶联；
3. **偶联**：10-DAB 的 C7 位 TBS 保护（TBSCl + 咪唑）→ C13 位选择性酯化（侧链酸 + DCC/DMAP，或 β-内酰胺 + 碱）→ 去保护（HF/吡啶 或 TBAF）；
4. **精制**：柱层析 → 结晶（乙腈/水或乙酸乙酯/甲苯）→ 紫杉醇（≥98%）；
5. **全合成（隐藏成就）**：从苯/丙烯出发的 Nicolaou/Holton 路线（40–46 步），游戏内压缩为 14+ 个里程碑反应。

### 3.2 表征验收（六项同时达标）

| 项 | 方法 | 标准 |
|---|---|---|
| 纯度 | HPLC（C18） | ≥98.0% |
| 手性 | 手性 HPLC（环糊精/纤维素柱） | ee ≥98% |
| 结构 | ¹H/¹³C NMR（600 MHz） | 与标准谱峰匹配 ≥95% |
| 分子量 | 高分辨 MS | [M+H]⁺ 854.34 ± 0.01 |
| 物性 | 旋光/熔点/XRD | [α]D −49°±2°；mp 211–216 °C；XRD 匹配 |
| 活性 | 微管蛋白聚合 + 海胆卵分裂抑制（1971 年原始 assay） | IC₅₀ 达标 |

- 任何一项不合格 → 返回纯化/重结晶/手性柱；ee 不合格整批报废；
- 研究手册记录全部谱图与判定，作为通关证据。

### 3.3 中试与 GMP

- 克级 → 公斤级逐级放大（混合/传热限制，收率折减）；
- GMP 洁净车间（阶段 7）+ 连续 3 批验证 + 留样；
- 中试稳定 → 通关。

### 3.4 稀土分离（真结局前置）

- 独居石/氟碳铈矿 → 酸/碱分解 → 混合稀土氯化物；
- 溶剂萃取级联（TBP/P507，混合澄清槽，多级逆流）→ 单一稀土（Y/La/Ce/Nd）99.99%+；
- 离子交换精制；钍/铀副产（放射性）安全处置；
- 产物：Y₂O₃（YBCO）、La₂O₃（镍基）、Nd（钕铁硼磁体——迈斯纳悬浮的磁源）。

### 3.5 超导材料（真结局）

**YBCO（1987，Tc 93 K，液氮温区）**：

- Y₂O₃ + BaCO₃ + CuO 按 Y:Ba:Cu = 1:2:3 球磨混合 → 压片 → 900–950 °C 烧结 → **氧气退火 450 °C**（控氧，x 影响 Tc）→ 块材；
- 验证：液氮（77 K）中迈斯纳悬浮（钕铁硼磁体）+ 四探针零电阻 + XRD 物相（正交 123 相）。

**铁基 SmFeAsO₁₋ₓFₓ（2008，Tc 55 K，液氦）**：

- 砷（毒砂/雄黄焙烧 → As₂O₃，剧毒）→ 高纯 As；SmF₃（HF 链）；
- 原料混合 → 真空密封石英管 → 1150 °C 固相反应 → 淬火；
- 验证：液氦（4.2 K）中悬浮/四探针；XRD 相纯。

**镍基 La₃Ni₂O₇（2023，14 GPa，Tc ~80 K）——真结局**：

- 稀土分离得 La₂O₃；NiO 高纯；
- 前驱体固相合成 → 高压下（14–43.5 GPa）超导；单晶可用高压浮区法（游戏内以六面顶压机模拟）；
- 高压技术：六面顶压机（碳化钨顶锤）→ HPHT 金刚石合成（5–6 GPa、1300–1500 °C，Fe/Ni 触媒）→ 金刚石对顶砧（DAC）+ 铼垫片（辉钼矿烟尘提铼）；
- 压力标定：红宝石荧光位移（R1 线随压力红移）；
- 测量：高压原位四探针（微电极 + 氧化铝绝缘）+ 磁化率（原位线圈）；
- 判定：电阻在 ~80 K 骤降 ≥3 个数量级 + 抗磁信号；**独立复现 3 次**（排除接触电阻/杂质相假象）。

### 3.6 低温与测量

- 液氦：天然气提氦 → 液化（节流/膨胀机）→ 杜瓦；4.2 K；
- 四探针：恒流源 + 纳伏表；接触电阻处理；
- 磁化率：SQUID? 本阶段用互感线圈/霍尔传感器（简化）；
- 数据：I-V 曲线、R-T 曲线、χ-T 曲线；误差分析。

### 3.7 科研诚信

- 每个结论至少 3 次独立实验；
- 排除假象（接触电阻、短路、杂质相、样品杆背景）；
- "同行评议"关卡：随机事件（审稿人质疑）→ 补实验；
- 不虚构常压室温超导（真结局止于 80 K/14 GPa）。

### 3.8 安全

- 砷/砷化氢、HF、锇（Sharpless 双羟化）、叠氮化物；
- 高压（GPa）设备失效、金刚石砧炸裂；
- 液氦/液氮冻伤与窒息；放射性（独居石钍）。

## 5. 工艺链详细设计

### 5.1 红豆杉种植与 10-DAB 提取（8–10 h）

育苗/种植 → 针叶采收（不毁树）→ 干燥/粉碎 → 醇浸提 → 浓缩 → 萃取 → 柱层析 → 结晶；10-DAB 含量约 1 g/kg 鲜叶（0.1%），提取率/纯度决定成本；种植周期是长线规划。

### 5.2 侧链合成（10–14 h）

苯甲醛 + 醋酐 → 肉桂酸 → 酯化 → Sharpless 不对称双羟化（AD-mix-β，ee ≥95%）→ 环化/胺化 → 苯甲酰化 → 侧链酸；或 β-内酰胺路线（Holton）；锇催化剂回收（贵金属/剧毒）。

### 5.3 保护、酯化与去保护（8–10 h）

10-DAB 的 C7-TBS 保护 → C13 选择性酯化（DCC/DMAP 或 β-内酰胺/碱）→ 去保护（HF/吡啶、TBAF）；每步 TLC/HPLC 监控；保护基正交是成败关键。

### 5.4 精制与表征（8–10 h）

柱层析 → 结晶 → 六项表征（HPLC/手性 HPLC/NMR/MS/旋光/熔点/XRD/活性）；不合格重结晶/手性柱；研究手册记录全部数据。

### 5.5 中试与 GMP（8–10 h）

克级 → 公斤级（反应釜放大、混合/传热、收率折减）→ GMP 车间 → 连续 3 批 → 通关。

### 5.6 稀土分离（10–12 h）

独居石/氟碳铈矿分解 → 混合稀土 → 萃取级联（TBP/P507）→ 单一稀土 99.99%+；钕铁硼磁体（Nd₂Fe₁₄B，1984）用于悬浮演示；钍/铀安全处置。

### 5.7 YBCO（6–8 h）

Y₂O₃ + BaCO₃ + CuO 球磨 → 压片 → 900–950 °C 烧结 → 氧气退火 450 °C → 液氮悬浮 + 四探针 + XRD。

### 5.8 铁基超导（8–10 h）

As₂O₃（剧毒）→ 高纯 As；SmF₃；原料混合 → 真空石英管 → 1150 °C → 淬火；液氦悬浮/四探针；XRD 相纯。

### 5.9 高压技术（10–14 h）

六面顶压机（液压 + 碳化钨顶锤）→ HPHT 金刚石（5–6 GPa/1300–1500 °C）→ DAC（金刚石砧 + 铼垫片）→ 红宝石荧光标压 → 14–43.5 GPa。

### 5.10 镍基超导（10–14 h）

La₂O₃ + NiO 前驱体 → 高压合成（14 GPa）→ 原位四探针（R-T）+ 磁化率（χ-T）→ ~80 K 骤降 ≥3 个数量级 + 抗磁 → 独立复现 3 次 → 真结局。

## 7. 里程碑与阶段出口

**主线（紫杉醇）六项判定：**

1. **10-DAB**：提取 ≥95%；
2. **侧链**：Sharpless 双羟化 ee ≥95%；

**真结局（超导）递进：**

1. **YBCO**：液氮悬浮 + 四探针 + XRD（1987 复刻）；

3. **La₃Ni₂O₇**：14 GPa 高压合成 + 原位四探针 ~80 K 骤降 + 抗磁 + 复现 3 次（2023 复刻）→ **真结局**。

**通关界面**：展示全部里程碑 + 现实对照年表（1831–2023）；隐藏成就「46 步的浪漫」（全合成路线）。

## 10. 实现要点（技术）

- **多步合成**：每步反应/纯化/表征；保护基正交；收率累乘；
- **手性**：ee 作为质量属性；手性柱分离；不对称催化条件 → ee 模型；
- **表征**：NMR/MS/HPLC/旋光/熔点/XRD 读取质量组件；谱图比对；误差；
- **活性实验**：微管蛋白聚合/海胆卵分裂抑制（概率模型 + IC₅₀）；
- **中试放大**：反应釜容量/传热/混合 → 收率折减；GMP 批次；
- **稀土**：萃取级联（级数/相比/萃取剂）→ 纯度；
- **超导**：材料相（XRD）、Tc、迈斯纳/零电阻判定；高压/低温参数；
- **科研诚信**：复现次数、假象排除、审稿事件；
- **数据驱动**：全部条件/判定 JSON 化。
