## 1. 设计定位：本阶段要教的六个"终身技能"

1. **还原与造渣**——铁矿石不是"熔化"出来的，是用 CO 还原出来的：Fe₂O₃ + 3CO → 2Fe + 3CO₂；同时必须造渣（CaO + SiO₂ → CaSiO₃），否则炉渣黏死、铁损失。
2. **碳含量**——同一炉铁，碳含量决定它是熟铁（<0.1%）、钢（0.2–0.8%）还是生铁（3.5–4.5%）；火花法测碳是本阶段的核心"仪器"。
3. **高温与炉衬**——1500 °C 以上的高炉需要耐火黏土/石英炉衬、水冷风嘴（本阶段为风嘴外部水套）、强力鼓风。
4. **硝化**——硝石不是矿，是"种"出来的：硝床里硝化细菌把氨氧化成硝酸盐，再与钾结合成 KNO₃；浸取 + 重结晶是纯度第一课。
5. **爆破**——黑火药 75:15:10 的配比、湿磨防爆、造粒、导火索；从"烧火"到"可控能量释放"。
6. **气体检测**——戴维灯（铁纱网）判瓦斯、金丝雀判 CO、通风与风门；矿井安全是阶段 3 深井采煤的入场券。

## 2. 开局与世界生成

### 2.1 出生点保障

阶段 2 的矿区（或阶段 1 出口任务指向的区域）保证：

- **铁矿**：磁铁矿（黑色、有磁性、条带状）、赤铁矿（红褐色）、褐铁矿（黄褐）、菱铁矿（灰色，需焙烧）；
- **石灰石**（助熔剂，阶段 0 已在用）、**耐火黏土**（高铝黏土，炉衬）；
- **黄铁矿**（淡黄色立方晶体，硫源）、**硝土**（洞穴、畜舍、堆肥堆附近的含硝土壤）；
- 河流（水车动力）、森林（木炭）。

### 2.2 原版内容调整（本阶段生效范围）

- 铁工具/铁器只能由本阶段炉窑产出；原版铁砧、铁轨、铁门等配方重做（铁锭 + 锻造）；
- 禁用原版熔炉炼铁；高炉是多方块结构，不是原版高炉方块；
- 火药只能由本阶段硝石 + 硫磺 + 木炭配制，原版火药配方删除；
- 矿井结构（竖井、支架、风门）成为可建造方块组；
- 阶段 1 的玻璃、酒、肥皂等继续可用。

### 2.3 气候与季节

- 木炭消耗是阶段 1 的数倍（炼铁 1 吨铁约需数吨木炭），逼玩家建木炭窑群/水车鼓风；
- 冬季矿井排水结冰、硝床活性下降（硝化细菌 20–30 °C 最活跃）；
- 雨季高炉料仓受潮 → 炉况波动。

## 3. 核心机制

### 3.1 炉温阶梯

| 设备 | 温度 | 产物 | 关键 |
|---|---|---|---|
| 块炼炉（bloomery） | 1200–1300 °C | 海绵铁（含渣） | 低温固态还原，不熔化 |
| 高炉（blast furnace） | 1400–1600 °C | 生铁（3.5–4.5% C） | 液态出铁、连续造渣 |
| 重熔炉/化铁炉 | 1150–1250 °C | 铸铁件 | 生铁重熔浇铸 |
| 坩埚炉 | 1300–1400 °C | 坩埚钢 | 高碳钢 + 坩埚密封 |

### 3.2 鼓风：从人力到水车

- 脚踏/手拉风箱（阶段 1 已有）→ **水车鼓风**：立式水轮 + 曲柄/凸轮 + 双风箱，风量成倍提升；
- 风量决定炉温上限与炉容；高炉风口风速不足 → 炉缸堆积、冻炉；
- 风嘴外部水套（本阶段用陶/铜套 + 水冷）防烧熔。

### 3.3 造渣与碱度

- 炉渣碱度 = CaO/SiO₂（质量比）；木炭高炉（硫少）常用 **0.7–0.9** 的酸性渣，每吨生铁加石灰石约 90–110 kg；
- 渣太酸 → 黏、排不出；渣太碱 → 炉衬侵蚀、铁水粘；
- 渣色/流动性是炉况的"仪表"：灰白玻璃状=正常，黑渣=FeO 高（还原不足），黄绿=硫高。

### 3.4 碳含量与热处理

- **熟铁**（<0.1% C）：软、韧、可锻焊；块炼海绵铁锻打排渣得到；
- **钢**（0.2–0.8% C）：渗碳（木炭 + 密封泥箱，900–950 °C，4–20 h，渗层 0.5–2 mm）→ 淬火（800–850 °C 入水/油）→ 回火（200–400 °C 消脆）；
- **生铁**（3.5–4.5% C）：硬、脆、熔点低（1150–1300 °C），可铸不可锻；
- **火花法测碳**：砂轮打磨看火花——低碳火花少、末端分叉少；高碳火花多、爆裂明显；熟练玩家可估 0.1% 级。

### 3.5 硝石：种出来的矿物

- 硝床：畜粪/尿液 + 草木灰（钾源）+ 石灰（中和酸性）+ 疏松土壤，好氧、保湿、20–30 °C，定期翻堆，6–12 个月；
- 硝化细菌（亚硝化菌/硝化菌）把 NH₄⁺ → NO₂⁻ → NO₃⁻，与 K⁺ 结合成 KNO₃；
- 浸取（热水）→ 过滤 → 蒸发结晶 → 粗硝（60–80%）→ 重结晶（溶解度随温度变化）→ 精硝 95%+。

### 3.6 火药与爆破

- 配比：KNO₃ 75 : S 15 : C 10（质量）；
- **湿磨**（加水研磨，防静电/摩擦引爆）→ 造粒（湿法过筛）→ 低温干燥（<50 °C）；
- 导火索：麻绳浸硝/醋（燃烧速度可控）；爆破：钻孔 → 装药 → 封泥 → 点火 → 撤离；
- 黑火药是**爆燃**（deflagration）不是爆轰，威力有限但足以碎石。

### 3.7 矿井与安全

- 竖井/斜井 + 木/石支架；排水（链泵/水车）；通风（风井 + 火炉抽风/风门）；
- **瓦斯（CH₄）**：戴维灯——铁纱网散热，火焰在网内燃烧不引燃外界；火焰变长/发蓝=瓦斯；
- **CO**：无色无味，金丝雀先倒（小动物敏感）——最原始的"气体检测仪"；
- 粉尘：煤尘/硫尘爆炸风险（阶段 3 采煤后更严重）。

## 5. 工艺链详细设计

### 5.1 探矿与选矿（2–3 h）

磁石吸附磁铁矿（真实！）；赤铁矿靠颜色；菱铁矿需焙烧（FeCO₃ → FeO + CO₂，600–800 °C）后才有磁性。选矿：破碎 → 手选 → 水洗（提高品位 30–50% Fe），本阶段无浮选/磁选机，靠人工。

### 5.2 块炼铁（3–5 h）

块炼炉：黏土/石砌竖炉 + 风嘴 + 木炭 + 矿石交替装料；1200–1300 °C 还原 4–8 h → 海绵铁块（含渣 20–40%）→ 趁热锻打（900–1100 °C）排渣 → 熟铁坯。收率：矿石 → 熟铁约 20–30%（真实块炼法很低）。

### 5.3 锻铁与钢（3–5 h）

折叠锻打（反复加热-锤打-折叠）均匀成分、排渣；渗碳：熟铁 + 木炭粉装入密封泥箱，900–950 °C 保温 4–20 h → 表层高碳 → 锻合/淬火/回火 → 钢；火花法判碳；不合格可重渗/脱碳（氧化气氛加热）。

### 5.4 高炉（5–8 h，本阶段 Boss）

炉体加高 + 水车强鼓风 + 石灰石助熔；1400–1600 °C 液态出铁（每 2–4 h 出一次），渣从渣口排出；炉料：矿石 + 石灰石 + 木炭（本阶段无焦炭）；渣碱度 0.7–0.9；故障：冻炉（风量不足/炉料湿）、结瘤（渣黏/局部过冷）、出铁口堵塞（烧穿/氧? 本阶段用钢钎）。

### 5.5 坩埚钢与铸铁（2–4 h）

坩埚钢：高碳铁 + 木炭装入密封坩埚，1300–1400 °C 保温 2–4 h → 成分均匀的高碳钢（乌兹钢原型）；铸铁：生铁重熔 1150–1250 °C → 浇入砂型/金属型 → 锅/管/砧。

### 5.6 水车鼓风（2–3 h）

立式水轮 + 曲柄连杆 + 双风箱；水量/落差决定功率；水车也可带锻锤（水锤）与磨盘——**机械动力的第一次规模化**。

### 5.7 黄铁矿 → 硫磺与绿矾（2–3 h）

- 干馏（隔绝空气 400–600 °C）：FeS₂ → FeS + S（硫蒸气冷凝得硫磺）；
- 焙烧（过量空气 600–800 °C）：4FeS₂ + 11O₂ → 2Fe₂O₃ + 8SO₂↑（**SO₂ 有毒**，通风/上风口）；
- 氧化 + 水：FeS₂ + H₂O + O₂ → FeSO₄·7H₂O（绿矾），是阶段 3 硫酸的原料（绿矾干馏出"矾油"）。

### 5.8 硝石（跨阶段长周期，2–3 h 操作 + 等待）

建硝床（畜粪 + 草木灰 + 石灰 + 土）→ 翻堆/保湿 6–12 个月（游戏时间可压缩但保留"等待"节奏）→ 浸取 → 过滤 → 蒸发结晶 → 粗硝 → 重结晶 → 精硝 95%。硝石产量决定火药与阶段 3 硝酸的规模。

### 5.9 火药与爆破（2–3 h）

湿磨（水 + 木球磨）→ 造粒 → 低温干燥 → 装药/导火索；爆破采矿：人工钻孔（钢钎 + 锤）→ 装药 → 封泥 → 点火 → 撤离；爆破效率 vs 安全（哑炮处理、早爆）。

### 5.10 矿井与安全（2–4 h）

竖井 + 支架 + 链泵排水 + 风井通风 + 风门；戴维灯判瓦斯；金丝雀判 CO；瓦斯超限 → 禁止明火/撤离；塌方（支护不足）、透水（误穿含水层）为真实事故。

### 5.11 铸铁与铁器（2–3 h）

铸铁锅/管/砧；锻铁工具/钉/铆钉/板；铁丝（拉丝模，阶段 3 织网/弹簧）；铁器用于阶段 3 的蒸馏器、泵阀、搅拌器。

## 7. 里程碑与阶段出口

**八项必需（研究手册逐条记录）：**

1. **块炼铁**：海绵铁 → 锻打 → 熟铁坯（排渣充分）；
2. **钢**：渗碳 + 淬火 + 回火，火花法判定 0.2–0.8% C；
3. **高炉出铁**：生铁成分合格、渣碱度在窗口、连续出铁 2 次以上；
4. **水车鼓风**：水车带动双风箱，炉温稳定 1500 °C+；
5. **硫磺与绿矾**：黄铁矿干馏/焙烧各一批（SO₂ 安全达标）；
6. **精硝**：重结晶后 95%+（滴定/焰色? 本阶段用燃烧试验与结晶形态判定）；
7. **黑火药 + 爆破**：配比正确、湿磨安全、成功爆破一处矿脉；
8. **矿井安全**：戴维灯/通风/排水齐备，安全下井 3 次。

**出口任务「煤与矾的召唤」**：找到煤层露头（黑色、可燃）并采集；用绿矾干馏出少量"矾油"（阶段 3 硫酸的预览），研究手册解锁阶段 3 条目："酸，是湿法化学的钥匙。"

## 8. 挑战与事故清单

| 事故 | 触发 | 后果 |
|---|---|---|
| 高炉冻炉/结瘤 | 风量不足、炉料湿、渣碱度错 | 停产/拆炉重砌，损失大量木炭与时间 |
| 铁水/渣喷溅 | 出铁口潮湿、水接触铁水 | 爆炸性喷溅 + 重度烫伤 |
| CO 中毒 | 炉顶煤气、矿井 | 无声昏倒；金丝雀/通风 |
| 瓦斯爆炸 | 明火 + CH₄ 超限 | 矿难，设备损毁 + 伤亡 |
| 火药事故 | 干磨/静电/摩擦/干燥过热 | 爆燃，工坊损毁 |
| SO₂ 中毒 | 黄铁矿焙烧 | 咳嗽/窒息；上风口/湿布 |
| 塌方/透水 | 支护不足、误穿含水层 | 矿难，通道堵塞 |
| 木炭危机 | 炼铁燃料需求 | 森林砍伐/木炭窑扩建，逼向阶段 3 的焦炭 |

| 第 12–13 天 | 矿井支护/排水/通风、戴维灯 | 3–4 h |
| 第 14 天 | 出口任务（煤 + 矾油） | 2 h |

## 10. 实现要点（技术）

- **块炼炉/高炉**为多方块：炉身、风口、出铁口、渣口、水套；温度由风量、燃料、炉料、炉衬决定；
- **炉料与渣**：矿石品位、石灰石配比、渣碱度实时计算；渣黏度影响排渣；
- **碳含量**：钢/生铁用 Data Component（`carbon` 0–4.5%），驱动硬度/脆性/可锻性；火花法为 UI 测试；
- **水车**：机械动力方块，转速/扭矩驱动风箱/锻锤/磨盘（阶段 4 蒸汽机沿用同一套动力系统）；
- **硝床**：BlockEntity 计时 + 翻堆/保温操作；产量随维护质量波动；
- **火药**：配方 + 湿磨/造粒/干燥工序；错误操作触发爆燃事件；
- **矿井气体**：世界生成时埋入瓦斯囊；戴维灯检测（火焰变化）；金丝雀实体（CO 指示）；
- **数据驱动**：矿石成分、炉温窗口、渣碱度、产率 JSON 化。
