# 阶段 0 详细设计：石器时代——火与陶（8–12 h）

> 所属总纲：[game-progression.md](game-progression.md) 阶段 0

## 1. 设计定位：本阶段要教的六个"终身技能"

1. **温度观察**——无温度计时代的火色/烟色判温（暗红 600 °C → 亮橙 900 °C → 黄白 1100 °C+）。这套技能一直用到阶段 2 的火花测碳、阶段 4 的铂网温度目测，是所有窑炉操作的基本功。
2. **原料加工观念**——天然矿物（黏土/石灰石/草木灰）必须经过淘洗、浸取、蒸发、过滤才能成为"原料"。这是选矿与提纯的第一次实践。
3. **容器即反应器**——陶锅是玩家的第一台反应器：煮食、煮盐、浸取、蒸发全部发生在陶器里。阶段 3 的烧瓶、阶段 7 的反应釜都是它的直系后代。
4. **燃料经济**——热值、燃烧完全度、耐火度、保温。木炭热值约为木柴两倍且无烟，这个事实直接决定阶段 1 冶炼用什么燃料。
5. **配方观念**——黏土掺砂防裂是"材料改性"第一课：**组分比例决定材料性能**，与后来的青铜配比、钢的含碳量、混凝土配比同构。
6. **副产物意识**——石灰窑放出"看不见的气"（CO₂，比空气重、能灭火），木炭窑放出木醋液/木焦油。化学工业从第一天起就是"联产"的。

## 2. 开局与世界生成

### 2.1 出生点保障
出生点必在温带河流/湖泊附近，半径 500 格内保证存在：黏土（河岸/湖底/沼泽）、石灰石露头（沉积岩）、石英砂（河滩）、燧石结核（河滩/石灰岩层）、以及**盐源三选一**（海岸盐田 / 盐湖 / 岩盐蒸发岩露头）。丘陵/山地边缘可见孔雀石、蓝铜矿、锡石、黄铁矿露头（此刻只能捡拾与认知，不能冶炼——冶炼需要阶段 1 的鼓风窑）。

### 2.2 原版内容调整（本阶段生效范围）
- 禁用原版全部合成配方、原版熔炉配方、原版木/石工具配方（由燧石打制替代）。
- 移除亡灵类/魔法类怪物（僵尸、骷髅、苦力怕等）；敌对威胁替换为**野生动物**（狼、野猪、熊，夜晚出没）+ **环境伤害**（失温、痢疾、饥饿）。
- 原版"喝水"删除，改为浑水 → 沉淀 → 煮沸链（见 5.10）。
- 挖掘等级：燧石工具可采软岩（黏土、砂、石灰石、盐岩）与软矿物露头（孔雀石等），**不可采**硬岩（花岗岩、玄武岩、各类硬矿石）。

### 2.3 天气与温度
存在雨、风、昼夜温差与冬季。**雨会毁掉露天晾晒的坯件与堆烧窑**；夜间失温（无篝火/火塘时掉血）——天气是工艺参数的一部分。

## 3. 核心机制：温度与火

### 3.1 火源分级（本阶段可用）
| 火源 | 温度区间 | 用途 |
|---|---|---|
| 篝火 | 500–800 °C | 烹饪、取暖、夜间驱兽 |
| 三石灶（陶炉箅） | 600–850 °C | 稳定烹饪、煮盐、蒸发 |
| 露天堆烧窑 | 800–950 °C | 第一批陶器（成功率低） |
| 坑窑 | 900–1000 °C | 正式烧陶、石灰煅烧 |
| 木炭窑 | 400–700 °C（闷烧） | 干馏木材制木炭 |

### 3.2 火色判温表（玩家可观察的反馈）
| 火色 | 约温 | 判定用途 |
|---|---|---|
| 暗红 | 550–650 °C | 堆烧预热段 |
| 樱桃红 | 700–800 °C | 素烧升温中 |
| **亮橙** | 900–950 °C | **陶器烧结窗口** |
| 黄 | ~1000 °C | 石灰煅烧窗口 |
| 黄白/白 | 1100 °C+ | 本阶段不可达（陶器会瘫软过烧） |

烟色判读：**黑烟 = 燃烧不完全**（缺氧/湿柴，浪费燃料+熏黑陶器）；**白烟 = 排湿**（含水汽）；**青蓝烟 = 完全燃烧**（燃料品质好）。

### 3.3 燃料热值（教学：为什么后来炼铜用木炭）
| 燃料 | 热值（相对值） | 特点 |
|---|---|---|
| 干草/秸秆 | 13 | 引火快、火弱、灰大 |
| 木柴 | 16 | 通用 |
| **木炭** | 29 | 无烟、火硬、灰少——窑炉与冶金的标配 |

燃烧管理输入：燃料粒度（劈细的柴烧得快）、通风（氧气）、堆料方式。所有反馈都通过火焰颜色与烟色呈现。

## 5. 工艺链详细设计

### 5.1 燧石打制与工具（开局 0.5–1 h）
- **采集**：河滩燧石结核（敲开得燧石核）。
- **打制**：燧石核 + 石锤（河卵石）在硬面敲击 → 燧石片（每核产 2–3 片，成功率 60–80%，失败产废片）。
- **组装**：燧石片 + 木棒 + 草绳 → 燧石斧/镐；燧石片 + 木柄 → 刮削器（剥皮、刮树皮）；木棍削尖 → 木矛。
- **数值**：燧石镐耐久 60（原版石镐 300 的 1/5）、挖掘速度 0.6×、采软岩有效；燧石斧伐木 1.5× 效率。耐久耗尽 → 剩木棒（重装燧石片）。
- **教学**：工具即"材料+结构"；打制失败产生废料（废片可作刮削器）。

### 5.2 取火与火种管理（关键节点，0.5 h）
- **方法一：钻木取火**（木杆 + 木板 + 草绒）——持续交互 1–3 分钟，耐力消耗，成功率随练习提升（30% → 70%）。
- **方法二：燧石 + 黄铁矿敲击取火**——燧石片 + 黄铁矿结核对敲 → 火星 → 草绒/炭绒（成功率 25–40%，但 10 秒一次，可反复尝试）。**黄铁矿是玩家接触的第一个金属硫化物**，研究手册自动记一条："黄色硬石，击打生火星，焙烧有呛鼻硫烟"——这是阶段 2–3 硫磺/硫酸链的最早伏笔。
- **火种保存**：陶罐装 1/3 闷烧炭火 + 草木灰覆盖 → **火种罐**（可随身搬运，持续 8 游戏小时，到期需续火）。教学：能源的保存与运输是人类文明的第一个工程问题。
- **失火风险**：篝火/火塘引燃 2 格内草与木质结构 → 石围/防火带（清理杂草）成为标准操作。

### 5.3 黏土采集与练泥（1–2 h）
- **采集**：河岸/湖底/沼泽的黏土层（徒手或木铲）。
- **淘洗**（选矿/分级第一课）：湿黏土 + 水搅拌成泥浆 → 静置沉降分级（粗砂先沉、细粉后沉、黏土悬浮最久）→ 取上层细泥浆 → 再沉淀 → 去水得净黏土。收率约 65%。
- **陈腐**：湿黏土堆置 1–2 游戏日（水分均匀、有机物分解），跳过则烧成率 −20%。
- **练泥**：反复揉练 + 摔打排泡（**气泡在烧成时膨胀 → 爆坯**）。交互：右键连续"揉练"动作条，含水率显示"偏干/合适/偏湿"（18–25% 为可塑窗口）。
- **掺砂配方**：净黏土 : 细砂 = 3:1 或 4:1。**不掺砂 → 干燥与烧成收缩开裂率 60%+**；掺砂过多 → 坯体松散强度不足。比例影响成品强度/致密度，是本作"组分-性能"机制的第一个实例。

### 5.4 制坯与干燥（1–2 h）
- **成型方式**：手捏（小件：碗/杯）、泥条盘筑（大件：罐/锅）、泥板拼接（钵）。
- **坯件用途定位**：陶碗（食/饮）、陶杯（饮/量取）、**陶罐**（储水 8 L/储粮/火种罐）、**陶锅**（煮食/煮盐/蒸发/浸取——第一台反应器）、陶钵（研磨/和泥/过滤承接）、陶炉箅（灶）、纺轮（阶段 1 纺织预告）。
- **阴干**：晾坯架 + 遮雨棚，1–2 游戏日，含水率降至 <5% 方可入窑（判定：敲击声由哑变脆、颜色由深变浅）。暴晒 → 开裂；淋雨 → 报废。
- **可刻划标记**：玩家可给陶坯刻字（信息记录雏形——陶罐刻"盐"/"水"）。

### 5.5 窑炉与烧成（本阶段 Boss，2–3 h）
**第一次：露天堆烧**（历史最原始方式）：地面铺柴 + 坯件堆 + 柴草覆盖点火，800–900 °C，受风雨影响，成功率 40–60%。
**升级：坑窑**：挖 3×3 坑 → 底部铺燃料 → 坯件码放（**留间距防粘连**）→ 覆土留烟道/观火孔 → 点火。

**烧成控温曲线**（真实陶艺三阶段，全部通过火色执行）：
1. **预热段**（100–200 °C）：小火排残余水。升温过快 → **爆坯**（窑内噼啪声，教学：水汽化体积膨胀 1700 倍）。
2. **升温/保温段**（至 900–950 °C）：加柴频率控制升温速率，火色维持**亮橙** ≥ 30 游戏分钟——这是"烧结窗口"：黏土颗粒间开始液相熔接。欠时 → 欠烧；过温（>1000 °C）→ 过烧瘫软变形。
3. **冷却段**：封窑缓冷 2–4 游戏小时。急冷 → 热震炸裂。

**出窑判定（玩家亲手操作）**：
- 敲击声：**清脆金属声 = 烧结合格**；沙哑 = 欠烧（吸水、易碎，可回窑重烧一次）。
- 滴水试验：滴水 3 秒不渗 = 合格；渗水 = 欠烧。合格标准：吸水率 <15%（陶器级）。
- 失败模式统计：欠烧（温/时不足）、过烧（变形粘连）、开裂（干燥不足/升温过快）、熏黑（明火直烧的碳沉积——**教学：还原气氛 vs 氧化气氛**；彩蛋：若整窑用湿草闷烧可得到**黑陶渗碳工艺**，龙山文化彩蛋成就）。

### 5.6 木炭窑（1–2 h）
- **原理**：木材干馏——隔绝空气加热 400–700 °C，挥发分（木煤气/木醋液/木焦油）逸出，留下木炭。**干馏/热解是玩家学的第一个"分解型"化学操作**。
- **工艺**：木材竖堆成垛（圆木 2–3 m）→ 覆土+草泥封顶 → 顶部烟孔 + 底部进气孔 → 底部点火 → 控进气量。
- **烟色进度判定**：白烟（排湿）→ 黄烟（炭化进行）→ **蓝烟（炭化完成，马上要过烧）→ 立即封孔** → 闷 24 游戏小时 → 开窑。
- **收率**：木炭约 27%（质量）；副产木醋液（烟道沟槽冷凝收集，量少——阶段 3 醋酸认知的伏笔）与木焦油（涂抹木柱防腐/黏合）。
- **质量判定**：敲击钢响 + 断面黑色金属光泽 + 燃烧无烟蓝焰。
- **价值锚点**：木炭热值 2× 木柴、无烟、灰少，是阶段 1 炼铜的还原剂兼燃料——本阶段末尾玩家应主动囤积。

### 5.7 石灰窑（1–2 h）
- **原理**：CaCO₃ → CaO + CO₂↑（900–1000 °C，强吸热——需长时间大火保温）。**这是玩家完成的第一个真正的化学转变**（质量守恒教学：烧后变轻了，"少掉的质量变成了看不见的气"）。
- **CO₂ 的观察**：石灰窑观火孔附近**火焰会被"看不见的气"压低/熄灭**；坑窑底部**低洼处会闷晕玩家**（头晕 debuff，需撤离通风）——教学：气体比空气重 + 燃烧产物有害（CO 第一课）。
- **工艺**：坑式石灰窑——石灰石块与木柴分层装填，煅烧保持黄火 2–3 游戏小时 → 停火自然冷却 → 得生石灰块 → 木杵/石锤粉碎得生石灰粉。
- **熟化（强放热反应第一课）**：生石灰 + 水 → 剧烈放热、冒汽沸腾、块体崩解（观察：水温可烫伤）→ 石灰膏/石灰乳（熟石灰 Ca(OH)₂）。
- **灰浆（建筑化学第一课）**：熟石灰 + 砂 + 水 → 石灰砂浆 → 砌石墙/窑炉内衬/抹面防水。硬化原理：Ca(OH)₂ + CO₂ → CaCO₃，在空气中缓慢"变回石头"（48 游戏小时达到可用强度）。
- **危险**：生石灰/熟石灰灼伤（强碱腐蚀 + 放热烫伤双重伤害）。
- **价值锚点**：石灰是全游戏使用率最高的无机物之一——玻璃、高炉造渣、索尔维制碱、漂白粉、水泥都要它（手册中预告条目）。

### 5.8 草木灰 → 钾碱（1–2 h）
- **原理**：草木灰含 K₂CO₃（含量 5–15%）——水浸取（固液萃取）+ 蒸发结晶，两个单元操作的第一次实践。
- **工艺**：收集篝火/灶的草木灰（**燃料副产，全程顺手积累**）→ 灰 + 热水搅拌浸取 → 草编网/陶钵+砂层粗滤 → 澄清 → 陶锅小火蒸发至干 → 灰白色粗钾碱结晶。或日晒蒸发（慢但省燃料）。
- **碱性的判定（无指示剂时代）**：① 手感滑腻；② **钾碱水 + 油脂搓揉 → 起皂沫**（皂化现象 = 最早的"碱性检测"，同时是阶段 1 制肥皂的直接预告）。
- **副产**：浸取后的灰渣作肥料（作物增产 15%——钾肥的最早形态）。
- **收率**：灰中 K₂CO₃ 10% × 浸出率 80% → 每单位灰约 8% 钾碱。

### 5.9 制盐（0.5–1 h）
- **海盐（盐田法）**：潮间带挖浅池 → 引入海水 → 日晒蒸发 → 粗盐结晶（需海岸；盐田需防雨排水）。
- **岩盐/盐湖**：内陆玩家的路径——蒸发岩露头直接采盐岩，或盐湖卤水煮盐。
- **提纯（简化）**：粗盐（含泥沙与苦卤 MgCl₂）→ 溶解 → 沙滤 → 再蒸发 → 食用盐（约 92%+）。苦卤的分离（镁化学）正式教学推迟到阶段 3+，此处只留观察："卤水有苦味，盐里混着别的东西"——**杂质概念第一课**。
- **判定**：结晶观察——盐晶为立方体（晶体学第一课，放大观察）。
- **用途**：腌制保藏（食物保质期 ×3）、调味（缺盐 → 乏力 debuff，电解质教学）；**价值锚点**：盐是无机化工之母（盐酸/氯碱/索尔维的原料），囤积。

### 5.10 生存与营养（贯穿全程）
- **饮水链**：浑水（河/湖）→ 陶罐静置沉淀 → 陶锅煮沸 → 安全水。饮未处理水 → 痢疾风险 30%（呕吐 + 持续掉血，2–3 游戏日）。
- **食物**：采集（浆果/野菜/块茎）+ 陷阱/木矛狩猎 + 烹饪。烤食食物价值 ×1.2；**陶锅煮食 ×1.3 且汤类同时补水**（烹饪容器的价值——陶锅为何是必需品）。
- **保藏**：盐腌 / 晾架风干（应对冬季与雨季）。
- **庇护与温度**：草棚 → 木棚；雨夜/冬季失温掉血，火塘取暖；兽皮披肩（生皮，简陋保暖）。
- **伤害处理**：捕猎受伤 → 有感染风险 debuff，处理 = 清水清洗 + 休息（药物化学在阶段 7，此处是生存压力）。

## 7. 里程碑与阶段出口（进入阶段 1 的判定）

**八项必需（研究手册自动逐条记录，全部点亮才解锁阶段 1 手册）：**
1. 燧石工具一套 + 火种罐（火种保存）。
2. 陶器三件套**烧结合格**：陶罐 + 陶锅 + 陶钵（敲击声/滴水判定通过）。
3. 木炭 ≥ 8 单位（燃烧无烟验证）。
4. 生石灰 + 熟化验证（遇水放热崩解）+ 灰浆砌筑一面石墙/一座窑炉。
5. 草木灰钾碱（油脂起沫验证）。
6. 盐 + 腌制品 ≥ 3 件。
7. 技能成就「看火」：3 次火色目测判定正确（暗红/亮橙/黄）。
8. 研究手册 ≥ 6 条工艺笔记（验证通过自动记录）。

**出口任务「青铜的召唤」**：在河滩/山麓发现并采集 1 块孔雀石/蓝铜矿/锡石露头（找矿教学：**颜色指示**——绿色/蓝色岩石），手册解锁阶段 1 预览条目："铜的冶炼需要更高的温度——鼓风"。

## 8. 挑战与事故清单（硬核点）

| 事故 | 触发 | 后果 |
|---|---|---|
| 爆坯/炸窑 | 升温过快、坯件含水>5% | 整窑损失 |
| 雨毁 | 晾晒/堆烧遇雨 | 坯件报废、窑火熄灭 |
| CO 中毒 | 木炭窑/石灰窑封窑期进入低洼处 | 头晕 debuff，持续暴露 → 昏迷 |
| 烧伤 | 取火/出窑/石灰熟化距离过近 | 高伤害 + 短暂 debuff |
| 石灰灼伤 | 生石灰遇水飞溅 | 碱腐蚀 + 烫伤双重伤害 |
| 失火 | 篝火引燃草/木 | 庇护所焚毁 |
| 痢疾 | 饮生水 | 呕吐 + 掉血 2–3 日 |
| 失温 | 雨夜/冬季无火 | 持续掉血 |
| 兽袭 | 夜间远离篝火 | 伤害 + 感染风险 |

**挫败感管理**：烧窑失败 → 手册自动记录失败原因（"升温过快""干燥不足"），下次有据可查；坯件可回窑重烧一次；材料全部可再生。

## 10. 实现要点（技术）

- **火色温度系统**：火焰粒子颜色 + 亮度按温度分 8 档；"凝视"火焰可查看估温（仅在学习「看火」后准确）。
- **陶坯 NBT**：含水率（干燥进程）、含砂率、烧结度（烧成后生成，驱动敲击声/吸水率判定）。
- **坑窑多方块判定**：结构完整 + 坯件含水 <5% + 燃料量 + 火色维持时长 → 出窑结算（每件独立判定：合格/欠烧/过烧/开裂）。
- **交互判定**：敲击陶器（右键 → 声音反馈）、滴水（显示吸水率）、揉练动作条、钻木取火小游戏。
- **时间**：1 游戏日 ≈ 20–30 现实分钟（可配置），干燥/闷烧/固化走游戏时间，支持离线/挂机积累。
