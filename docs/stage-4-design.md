## 1. 设计定位：本阶段要教的六个"终身技能"

1. **高压与循环**——压缩机、高压容器、未反应气循环、惰性气排放；合成本身只转化 15–20%，循环才是工业化的关键。
2. **催化与平衡**——V₂O₅ 的接触法、Fe 的合成氨、Pt-Rh 的氨氧化：温度与平衡、速率与催化剂中毒。
3. **电与电化学**——发电机、电解、电精炼、电池；电把化学从"热驱动"变成"电驱动"。
4. **分馏**——煤焦油按沸点切割；理论塔板与回流比；"一锅黑油"变成一串产品。
5. **有机合成基础**——硝化（混酸）、还原（铁 + 盐酸）、水蒸气蒸馏、重结晶；苯胺是第一个"平台中间体"。
6. **能量与机械**——蒸汽机、调速器、锅炉、压力表；负反馈控制第一次出现。

## 2. 开局与世界生成

### 2.1 出生点保障

阶段 4 的工业区保证：

- **煤/黄铁矿**（阶段 3 已有）、**石灰石/岩盐/硝石**；
- **铬铁矿**（重铬酸钾 → 苯胺紫氧化剂，染料链）；
- **方铅矿**（铅 + 银）、**砂铂矿**（铂族催化剂/电极）；
- 森林/木材（早期锅炉燃料）、河流（水车/蒸汽机冷却水）；
- 石英砂（玻璃/硫酸吸收塔填料）。

### 2.2 原版内容调整（本阶段生效范围）

- 蒸汽机/锅炉为多方块结构；原版熔炉/高炉继续禁用；
- 电力为直流系统（阶段 5 才交流并网）；红石系保持移除；
- 铁路与矿车升级为蒸汽机车牵引（物流）；
- 硫酸/硝酸为流体（浓度档独立）；苯胺等有机物为液体/固体物质；
- 炸药需要雷管起爆（导火索只能引燃黑火药）。

### 2.3 气候与季节

- 锅炉需要大量冷却水；冬季河流结冰影响水车与冷却；
- 合成氨的循环气冷却依赖冷却水温度（夏季产量下降）；
- 硝化反应对温度极敏感（夏季需冰/冷水机组）。

## 3. 核心机制

### 3.1 蒸汽动力

| 阶段 | 代表 | 压力 | 效率 | 关键 |
|---|---|---|---|---|
| 大气机 | 纽科门 1712 | 常压蒸汽 | ~1% | 冷凝产生真空，只用于抽水 |
| 分离冷凝器 | 瓦特 1769 | 0.1–0.2 MPa | 3–5% | 冷凝器独立、双向做功 |
| 高压机 | 特里维西克 1804 | 0.3–0.7 MPa | 5–10% | 高压锅炉、紧凑、可移动 |
| 多级膨胀/冷凝 | 19 世纪中后期 | 1–1.5 MPa | 10–20% | 多级汽缸、过热蒸汽 |

- 锅炉：铆接钢板/钢管、安全阀、压力表、水位计；超压 = 爆炸；
- 飞球调速器：转速 → 离心力 → 阀门开度（负反馈），是控制论的第一课；
- 蒸汽机驱动：矿井泵、鼓风机、锻锤、机床、机车、发电机。

### 3.2 电与电化学

- 电源：伏打电堆（1800）→ 丹尼尔电池（1836）→ 铅酸蓄电池（普兰特 1859，2.1 V/格）；
- 发电机：法拉第盘式（1831）→ 西门子自励直流发电机（1866，蒸汽拖动）；
- 应用：弧光灯（碳棒，~3000–4000 K）、电解水（H₂/O₂）、电解精炼铜（1865）、电镀；
- 电解精炼铜：粗铜阳极 / 纯铜阴极，CuSO₄ + H₂SO₄ 电解液，槽压 0.2–0.3 V，阴极铜 99.9%；阳极泥 → 金/银/铂/钯回收（贵金属链开始）。

### 3.3 分馏（煤焦油）

| 馏分 | 沸点范围 | 主要成分 | 用途 |
|---|---|---|---|
| 轻油 | <170 °C | 苯、甲苯、二甲苯 | 染料、炸药、溶剂 |
| 中油 | 170–230 °C | 萘、酚 | 苯酐、树脂、消毒剂 |
| 重油 | 230–270 °C | 蒽、咔唑 | 茜素染料 |
| 沥青 | >270 °C（450 °C 不挥发残渣） | 多环芳烃 | 电极粘结剂、防水 |

- 釜式间歇蒸馏 → 分馏柱（填料/塔板）→ 回流比控制；
- 苯/甲苯/二甲苯沸点接近（80.1/110.6/138.4 °C），需要高效分馏——阶段 6 精馏塔的预演。

### 3.4 有机合成基础

- **硝化**：苯 + 混酸（HNO₃ + H₂SO₄）→ 硝基苯（50–55 °C，强放热，必须控温）；
- **还原**：硝基苯 + 铁粉 + 盐酸 → 苯胺（Béchamp 1854，~100 °C）→ 碱析 → 水蒸气蒸馏；
- **氧化**：苯胺 + 重铬酸钾 → 苯胺紫（Perkin 1856）；蒽氧化 → 蒽醌 → 茜素；
- **重结晶/蒸馏**：产物提纯（阶段 3 的滴定/温度计在此派上用场）。

### 3.5 催化与平衡

- **接触法**：2SO₂ + O₂ ⇌ 2SO₃（ΔH = −197 kJ/mol），V₂O₅、~450 °C、1–2 atm、多段换热；SO₃ 用 98% H₂SO₄ 吸收 → 发烟硫酸 → 稀释；
- **合成氨**：N₂ + 3H₂ ⇌ 2NH₃（ΔH = −46 kJ/mol NH₃），Fe₃O₄-K₂O-Al₂O₃，400–500 °C、200 bar；平衡与速率在 450 °C 附近折中；
- **奥斯特瓦尔德**：4NH₃ + 5O₂ → 4NO + 6H₂O，Pt-Rh 网 800–900 °C，NO → NO₂ → 水吸收 → 60% 硝酸；
- 催化剂中毒：硫、氯、砷使催化剂失活——上游净化是合成氨的第一关。

### 3.6 高压与循环

- 多级往复压缩机（蒸汽驱动）→ 200 bar；高压容器（锻焊/多层卷焊）；
- 合成塔：催化剂床 + 内换热 + 冷激；出塔气冷却 → 氨冷凝分离 → 未反应气循环；惰性气（Ar/CH₄）排放（弛放气）；
- 尿素：2NH₃ + CO₂ ⇌ NH₂COONH₄（110 atm、160 °C，ΔH = −117 kJ/mol）→ 尿素（180–200 °C、150–200 bar，转化率 60–70%）→ 未反应物循环。

## 5. 工艺链详细设计

### 5.1 蒸汽机与铁路（6–10 h）

纽科门大气机（抽水）→ 瓦特分离冷凝器 + 飞球调速器 → 高压锅炉 + 双作用汽缸 → 蒸汽机车 + 钢轨；锅炉铆接/焊接、安全阀、压力表；调速器整定（比例带）是控制论第一课。

### 5.2 电与电池（4–6 h）

伏打电堆（Cu/Zn/盐水）→ 丹尼尔电池 → 铅酸蓄电池（充放电）→ 蒸汽拖动西门子发电机 → 弧光灯；电解水制 H₂/O₂（合成氨的氢源之一）。

### 5.3 电解精炼铜与阳极泥（3–4 h）

粗铜阳极 + 纯铜阴极 + CuSO₄/H₂SO₄ 电解液，槽压 0.2–0.3 V；阴极铜 99.9%；阳极泥收集 → 王水溶解 → 贵金属分离（Au/Ag/Pt/Pd）——阶段 7 铂族化学的起点。

### 5.4 煤焦油分馏（4–6 h）

釜式蒸馏 + 分馏柱：<170 °C 轻油（苯/甲苯/二甲苯）→ 170–230 °C 中油（萘/酚）→ 230–270 °C 重油（蒽）→ 沥青；回流比与塔板数决定分离度；苯的纯度用密度/折光/沸点判定。

### 5.5 硝化与苯胺（5–7 h）

混酸配制（HNO₃ + H₂SO₄，注意"酸入酸"）→ 苯硝化（50–55 °C，夹套冷却）→ 分液（有机相/酸相）→ 水洗/碱洗 → 蒸馏 → 硝基苯；铁粉 + 盐酸还原（100 °C）→ 碱析 → 水蒸气蒸馏 → 苯胺（避光保存，易氧化）。

### 5.6 染料（4–6 h）

- 苯胺紫（Perkin 1856）：苯胺 + 重铬酸钾 + 硫酸氧化 → 紫色染料 → 染丝绸/羊毛；
- 靛蓝（Heumann 1890）：苯胺 → N-苯基甘氨酸 → 碱熔 → 吲哚酚 → 空气氧化 → 靛蓝；染色需还原-氧化循环（保险粉/空气）；
- 染料牢度测试（水洗/日晒）是"质量"的第一课。

### 5.7 炸药（6–8 h）

- 硝化甘油（1847）：甘油 + 混酸，0–20 °C 严格控温 → 洗涤 → 硅藻土吸收 → 达纳炸药（1867，诺贝尔）；
- 硝化棉（1846）：棉纤维 + 混酸 → 无烟火药（胶化）；
- 雷汞：汞 + 硝酸 + 乙醇 → 雷汞（起爆药）→ 雷管；
- TNT（1863）：甲苯三段硝化（80–100 °C），一硝/二硝/三硝基甲苯分离；
- 苦味酸：苯酚磺化 → 硝化；安全：炸药车间隔离/防静电/限量。

### 5.8 接触法硫酸（6–8 h）

硫磺/黄铁矿 → SO₂（净化/干燥，防催化剂中毒）→ 转化器（V₂O₅，450 °C，多段换热）→ SO₃ → 98% H₂SO₄ 吸收 → 发烟硫酸 → 稀释 → 98% 硫酸；尾气碱洗（环保）。

### 5.9 合成氨（12–16 h，本阶段 Boss）

原料气：水煤气（焦炭 + 水蒸气）→ 变换（CO + H₂O ⇌ CO₂ + H₂）→ 脱硫（ZnO/活性炭）→ 脱碳（加压水洗/碱液）→ 压缩 200 bar → 合成塔（Fe 催化剂，450–500 °C）→ 氨冷凝 → 循环；弛放气排放；考核：氨纯度（滴定）、循环稳定、催化剂寿命。

### 5.10 奥斯特瓦尔德硝酸（5–7 h）

氨 + 空气 → 铂铑网 800–900 °C → NO → 冷却 → 氧化 NO₂ → 水吸收 → 60% 硝酸；尾气 NOx 处理；铂网回收（贵金属）。

### 5.11 尿素（6–8 h）

NH₃ + CO₂ → 氨基甲酸铵（110 atm、160 °C）→ 尿素（180–200 °C、150–200 bar）→ 减压分解未反应物 → 循环 → 蒸发造粒；缩二脲控制（温度/停留时间）。

### 5.12 氨制冷与冷链（3–4 h）

氨压缩制冷（沸点 −33.3 °C）→ 冷库/制冰 → 食品保鲜/冷冻干燥；氨泄漏检测（肥皂水/试纸）。

## 7. 里程碑与阶段出口

**十项必需（研究手册逐条记录）：**

1. **瓦特蒸汽机**：分离冷凝器 + 飞球调速器闭环稳定；
2. **发电机 + 弧光灯**：蒸汽拖动，连续点亮；
3. **电解精铜**：99.9% + 阳极泥收集；
4. **焦油分馏**：苯/甲苯/萘/酚/蒽分离（纯度判定）；
5. **苯胺**：硝化 + 还原 + 水蒸气蒸馏；
6. **染料**：苯胺紫或靛蓝，染色牢度测试；
7. **达纳炸药 + 雷管**：爆破对比实验；
8. **接触法 98% 硫酸**：转化率与吸收达标；
9. **合成氨**：循环稳定运行、氨纯度达标（**总门槛**）；
10. **奥斯特瓦尔德硝酸 + 尿素**：各一批合格产品。

**出口任务「电与氯的召唤」**：蒸汽发电机驱动电解槽，电解食盐水小批量制得 Cl₂ + NaOH + H₂（阶段 5 预览）；研究手册解锁阶段 5："电，可以把盐变成三样东西。"

## 8. 挑战与事故清单

| 事故 | 触发 | 后果 |
|---|---|---|
| 锅炉爆炸 | 超压/缺水/铆接缺陷 | 厂区损毁 + 伤亡 |
| 氢气泄漏 | 压缩机/管道密封失效 | 燃爆；肥皂水检漏 |
| 催化剂中毒 | 原料气硫/氯/砷超标 | 催化剂失效，换剂成本 |
| 硝化失控 | 冷却中断/加料过快 | 飞温、爆炸 |
| 炸药事故 | 静电/摩擦/超温 | 车间殉爆 |
| CO 中毒 | 水煤气/合成气泄漏 | 无声昏倒；氯化钯试纸检测 |
| 硝酸/硫酸灼伤 | 混酸配制、蒸馏 | 重度烧伤 |
| 合成氨循环失效 | 惰性气积累/氨分离不良 | 产量骤降、停车 |

## 10. 实现要点（技术）

- **蒸汽网络**：锅炉压力/水位/安全阀；蒸汽机转速-扭矩；调速器为 PID 雏形；
- **电力**：直流电网（电压/电流），发电机效率，电池充放电；
- **电解**：法拉第定律（电量 → 物质量），槽压/电流密度/选择性；
- **分馏**：理论塔板 + 回流比 → 馏分组成（与物质系统的过程流对接）；
- **硝化**：放热速率 + 夹套冷却 + 温度联锁；超温触发事故；
- **高压合成**：压缩机多级、循环回路、弛放气、催化剂中毒/寿命；
- **制冷**：氨压缩循环（蒸发/冷凝/节流），冷库温度；
- **数据驱动**：工艺参数（温度/压力/配比/收率）JSON 化，与分析仪器判定联动。
