# 《Immersive Chemical Industry》全流程设计：从燧石到紫杉醇

> 目标平台：Fabric 1.21.1（与本仓库一致）｜ 主线时长：**750–1000 小时**（含可选支线 1000+）
> 文档定位：游戏流程与科技树的总体设计，是后续内容开发的总纲。

---

## 0. 设计五原则（不可违反的铁律）

1. **物质真实**：所有物质、反应、催化剂、设备原理必须真实存在。反应条件可简化（压缩时间、简化传质细节），但不得改变反应的热力学方向或杜撰不存在的物质/捷径。
2. **无魔法**：红石、附魔、酿造、经验等"魔法系统"全部移除，一切自动化与增益必须来自真实技术（机械→气动→电气→数字）。
3. **从零自举**：开局一无所有（石器时代）；任何科技解锁的判定是"拥有设备 + 完成验证实验（用仪器证实产物）"，不存在凭空获得的知识点。
4. **纯度即进度**：收率 / 纯度 / 选择性（含手性 ee%）是贯穿全程的核心数值；没有分析仪器就没有"知识"，也就没有进度。游戏约一半时间在做"提纯"。
5. **历史即逻辑**：阶段顺序 = 人类化学工业史顺序 = 物理可行性顺序。历史之所以这样走，是因为每一步都恰好是"现有基础设施能支撑的下一步"，游戏不允许跳级。

## 1. 通关目标

### 1.1 主线通关：全合成紫杉醇（Paclitaxel）

紫杉醇（C₄₇H₅₁NO₁₄，853.9 Da）是天然产物全合成的丰碑（Nicolaou / Holton 1994 全合成；1992 年起商业化半合成），其侧链合成依赖**不对称催化**——2001 年诺贝尔化学奖（Sharpless / Noyori / Knowles）与 2021 年诺贝尔化学奖（List / MacMillan 有机小分子催化）的核心成果。用它作为通关目标，等于让玩家亲手复刻现代合成化学的最高成就。

**通关判定（六项同时达标）：**
1. **纯度**：HPLC ≥ 98.0%；手性 HPLC 对映体纯度 **ee ≥ 98%**（需自制手性固定相柱）。
2. **结构**：¹H/¹³C NMR 全谱与标准谱峰匹配 ≥ 95%（超导磁体 NMR，需液氦——链回空分/提氦）；高分辨质谱 [M+H]⁺ = 854.34 ± 0.01。
3. **物性**：旋光度 [α]D²⁰ = −49° ± 2°（c 1, MeOH，自制旋光仪）；熔点 213–216 °C；粉末 XRD 谱匹配。
4. **活性**：微管蛋白聚合促进实验 + 海胆卵分裂抑制实验（复刻 1971 年 Wani 的原始活性测定法）双双通过。
5. **工程**：中试产线连续 3 批收率 ≥ 60%、质量指标全合格（药品生产需通过 GMP 洁净车间认证）。
6. **存档**：1 g 紫杉醇单晶入库展示柜 → 通关界面展示全部里程碑 + 现实对照年表。

隐藏成就：**「46 步的浪漫」**——不走"提取 10-DAB + 侧链缩合"的半合成路线，而从苯/丙烯出发完成接近全合成的路线。

### 1.2 真结局（通关后追加）：高压镍基超导 La₃Ni₂O₇

使用 2023 年《Nature》报道的镍基高压超导（La₃Ni₂O₇，~14 GPa，Tc ≈ 80 K）作为真结局。设计上**故意不虚构"常压室温超导"**——游戏终点停在现实研究的前沿，尊重科学。

**递进式挑战（不可跳级）：**
1. **YBCO**（YBa₂Cu₃O₇₋ₓ，1987 年诺奖，Tc 93 K）：稀土分离（钇）→ 固相烧结 → 氧退火控氧 → **液氮中迈斯纳悬浮** + 四探针零电阻验证。
2. **铁基超导 SmFeAsO₁₋ₓFₓ**（2008 年细野团队，Tc 55 K）：砷/氟化物剧毒链 → 真空密封石英管固相反应 → **液氦中悬浮验证**（需天然气提氦 + 液化链）。
3. **镍基超导 La₃Ni₂O₇**（2023）：HPHT 人工合成金刚石（六面顶压机）→ 金刚石对顶砧 + 铼垫片 → 升至 ≥14 GPa → **高压原位四探针**：电阻在 ~80 K 骤降 ≥3 个数量级 + 原位抗磁信号 → 数据独立复现 3 次（"同行评议"关卡）→ 真结局 CG。

### 1.3 可选支线（非必要，均真实）

- **mRNA 疫苗支线**（2023 年诺奖生理学/医学）：合成 N1-甲基假尿苷（尿苷甲基化）→ 亚磷酰胺法固相合成短链 mRNA → HPLC 纯化 → 可电离脂质（ALC-0315 类多步合成）→ 微流控 LNP 组装 → 细胞转染验证。
- **人工淀粉合成支线（ASAP，2021 Science，中科院天津工业生物所）**：CO₂ + H₂ → 甲醇（ZnO-ZrO₂，5 MPa、315–320 °C）→ 酶级联 → 直链/支链淀粉（ASAP 1.0/2.0/3.0/3.1 四代阶梯，**实验室级，不做工业化**）。详见 [side-quest-artificial-starch.md](side-quest-artificial-starch.md)。
- **芯片支线**（第 8 阶段主线内容）：硅/锗单晶 → 光刻全流程 → 集成电路 → PLC/DCS。做芯片不是通关必需，但做出来会让仪器成本与自动化大幅改善。
- **全合成成就链**：维生素 B₁₂ 发酵（深坑）、可的松（甾体 11α-羟化生物转化）、全合成紫杉醇（隐藏成就）。

### 1.4 为什么这样设计通关

- **足够硬核**：通关要同时证明"能合成（有机化学）、能测准（分析化学）、能放大（化学工程）、能合规（GMP）"——这正是现实制药工业的四道门槛。
- **用到现代研究成果**：2001/2021 诺奖不对称催化（主线）、2023 镍基超导（真结局）、2023 诺奖 mRNA（支线）、2021 人工淀粉 ASAP（支线）、绿色化学（贯穿）。
- **闭环美学**：NMR 需要液氦，液氦来自第 5 阶段空分/第 6 阶段天然气，超导验证又需要 NMR 的磁体技术——终点设备全部由玩家 800 小时前打下的基础堆成。

## 2. 十大核心系统

### 2.1 温度与窑炉
热源分级：明火（~800 °C）→ 鼓风窑（~1200 °C）→ 焦炭炉（~1600 °C）→ 电弧炉（~3000 °C）。测温手段分级：目测火色 → 水银/酒精温度计（<350 °C）→ 热电偶（Pt/Pt-Rh，至 1700 °C）→ 光学高温计/红外。**温度不足 → 收率低/反应不发生；超温 → 设备损毁/副反应**。设备材质有耐温上限（陶 < 玻璃 < 铸铁 < 钢 < 石英/刚玉 < 石墨/碳化硅）。

### 2.2 反应与收率
每个反应 = 原料 + 催化剂 + 温度 + 压力 + 配比 + 时间 → 产物（带收率）+ 副产物。收率/选择性由条件决定，遵循真实规律：放热反应需控温、可逆反应遵循勒夏特列原理（如合成氨低温利于平衡但高温利于速率，存在最优区间——反应工程第一课）。压力分级：常压 → 蒸汽锅炉（~10 atm）→ 合成氨（200–300 atm）→ LDPE（~2000 atm）→ DAC（GPa 级）。真空分级：水冲泵（~30 torr）→ 旋片泵 → 油扩散泵（高真空，镀膜/质谱）。

### 2.3 分离与纯化（纯度阶梯，见附录 A）
固液：过滤 → 压滤；离心；结晶/重结晶（溶解度曲线）；干燥 → 真空干燥 → 冷冻干燥。
液液：萃取（分液）；蒸馏：简单 → 分馏（理论塔板数）→ 水蒸气蒸馏 → 减压蒸馏 → 连续精馏（回流比控制）。
吸附/色谱：活性炭脱色 → 硅胶柱层析 + TLC 监控 → 制备 HPLC → 手性柱；分子筛/离子交换树脂（软化水 → 去离子水 → 超纯水）。
气体：洗涤塔 → 变压吸附（PSA）→ 深冷空分 → 膜分离。
**纯度档位决定下游可用性**：工业级（95–98%）→ 化学纯 CP → 分析纯 AR → 色谱纯 → 电子级（ppb）→ 半导体级（9N–12N）。电子级 HF 与工业级 HF 是两个物品。

### 2.4 分析检测（解锁科技的总闸门）
滴定（酸碱/氧化还原/沉淀/配位）→ 物性（熔点、密度、折光、旋光、黏度）→ 仪器：pH 计（玻璃电极）→ 电导率 → UV-Vis → 折光仪 → GC → HPLC → IR → MS → NMR → XRD。每台仪器都是一条制造链（如 NMR = 液氦 + 铌钛线 + 射频电子 + 傅里叶变换计算机），**没有对应仪器就无法验证产物，无法验证就无法解锁下一步**。手性分子需旋光仪/手性 HPLC 测定 ee%，直通紫杉醇。

### 2.5 材料与腐蚀
容器/管道材质决定工艺上限：陶器 → 铜 → 铸铁 → 铅（耐稀硫酸）→ 玻璃（硼硅/石英）→ 搪瓷 → 不锈钢 304/316L（铬镍）→ 钛（耐氯离子）→ 哈氏合金（耐高温盐酸）→ 石墨 → PTFE 衬里。真实腐蚀规则：**浓硫酸可钝化碳钢，稀硫酸腐蚀碳钢**；玻璃怕 HF 与热浓碱；氯离子点蚀不锈钢。装错介质 = 腐蚀穿孔 + 事故。

### 2.6 能源与动力
人力/畜力 → 水车/风车 → 蒸汽机 → 汽轮机 + 发电机（交流电）→ 整流（汞弧 → 半导体）→ 电炉/电解。燃料：木柴 → 木炭 → 煤 → 焦炭 → 煤气 → 石油气/天然气 → 电。电力是电解（氯碱、铝、精炼铜）、电炉（电石、冶金硅、钨）、仪器与自动化的前提。单位简化：机械功 MJ / 电 kWh / 热值 MJ·kg⁻¹，带效率损失。

### 2.7 流体、管道与物流
陶管 → 铅管 → 铸铁管 → 钢管 → 不锈钢/衬里管；泵：手摇 → 蒸汽 → 电动；阀门：手动 → 气动 → 电动调节阀；计量：孔板/转子流量计。运输：矿车/马车 → 运河 → **蒸汽铁路**（原料产地分散，强迫建立真实物流网与工业区位决策）。

### 2.8 控制与自动化（红石的正式替代品）
自动化演进线全部真实可考：**机械凸轮（1801 雅卡尔提花织机穿孔卡 = 第一台可编程机器）→ 瓦特飞球调速器（负反馈第一课）→ 气动逻辑元件（AND/OR/NOT 气动实现）→ 继电器梯形图 → 真空管 → 晶体管 → 集成电路 → PLC → DCS 中央控制室（PID 整定）**。红石物品对照替代：红石粉 → 仪表信号线（4–20 mA）；火把 → 继电器；比较器 → 变送器；侦测器 → 传感器（温度/压力/流量/液位/气体）；活塞 → 气动/液压缸；漏斗 → 料仓 + 输送带；命令方块 → DCS 组态界面。**自动化不是免费外挂，而是 700 小时后用芯片、仪表、执行器拼出来的真实控制工程。**

### 2.9 地质、采矿与选矿
真实岩层（沉积/变质/火成岩）与矿床类型：斑岩铜矿（黄铜矿）、条带状铁矿（磁铁矿/赤铁矿）、铝土矿、方铅矿/闪锌矿共生、锡石砂矿、铬铁矿、黑钨矿/白钨矿、辉钼矿、独居石（稀土，伴生钍放射性）、沥青铀矿（辐射）、岩盐/钾盐/硝石（蒸发岩）、磷灰石、萤石、重晶石、石膏、硫磺、石墨、金刚石（金伯利岩筒，深部）、煤（褐煤→无烟煤按变质程度）、石油/天然气（背斜圈闭，需钻探）。采矿：手工 → 火药爆破（需安全炸药+雷管）→ 机械开采；矿井需支护、通风、排水，瓦斯（CH₄）爆炸风险（戴维安全灯/甲烷检测）。**选矿**：破碎 → 磨矿 → 重选（淘洗/摇床）→ 磁选 → 浮选（捕收剂黄原酸盐 + 起泡剂松醇油 + 抑制剂）→ 浸出（湿法冶金 SX-EW）。品位与尾矿管理贯穿始终。

### 2.10 安全、事故与环保（硬核的核心来源）
- 毒气：CO、H₂S、Cl₂、SO₂、NOₓ、NH₃、光气、HCN、苯（慢性）、HF（烧伤）、汞蒸气、OsO₄、砷化氢。
- 爆炸：粉尘爆炸（煤粉/铝粉/面粉）、可燃气爆炸极限（H₂ 4–75%、CH₄ 5–15%）、压力容器超压、硝化物/重氮盐/过氧化物（乙醚与 THF 蒸馏前须 KI 试纸检测）、叠氮化物。
- 腐蚀/灼伤/辐射（铀钍矿）。
- PPE 链：皮围裙 → 橡胶手套 → 活性炭防毒面具 → 丁基橡胶防化服 → 正压呼吸器 → 铅围裙；工程防护：通风橱 → 工业排风 + 洗涤塔 → 全封闭工艺 + 联锁。
- **环保事件线（真实历史，触发绿色工艺解锁）**：伦敦烟雾（1952，强制脱硫/无烟煤）→ 水俣病（汞法氯碱 → 强制离子膜法）→ 铅（四乙基铅抗爆剂 → 无铅汽油 + 催化重整）→ 洗涤剂泡沫河（支链 ABS → 直链 LAS）→ 臭氧层（CFC → HCFC/HFC）→ 富营养化（含磷洗衣粉 → 4A 沸石）→ 微塑料/碳中和（后期）。排放超标 → 土地/水源区块污染 → 减产 + 惩罚；绿色路线达标 → 成就与效率奖励（如 HPPO 法制环氧丙烷、甘油法环氧氯丙烷、两步发酵法维生素 C）。

## 3. 十大阶段

> 每阶段 = 定位 / 关键链 / 里程碑（解锁判定）/ 硬核点。时长按单人熟练玩家估计。

### 阶段 0｜石器时代：火与陶（8–12 h）
> 📘 详细设计（机制/数值/配方/里程碑）：见 [stage-0-design.md](stage-0-design.md)。
**定位**：一切化学工业的开端是"温度"与"容器"。
**关键链**：燧石工具 → 采黏土/石灰石/砂 → 露天堆烧窑（800–950 °C）→ 陶器（防裂配砂，以敲击声/吸水率判断烧结度）→ 闷烧木炭窑 → 石灰窑（CaCO₃ → CaO，900–1000 °C）→ 熟石灰灰浆；草木灰浸取 → 钾碱 K₂CO₃；晒盐/煮盐。
**里程碑**：① 第一件不渗水陶器（窑温达标）；② 木炭（燃料升级）；③ 生石灰 + 熟化；④ 草木灰碱结晶。
**硬核点**：无温度计，用火色/烟色判温；黏土配比试错；燃料与雨季管理。

### 阶段 1｜青铜时代：冶金·玻璃·发酵（20–30 h）
**定位**：选矿与冶金是化工的原料处理之根；玻璃开启"观察"；发酵开启"生物"。
**关键链**：露头找矿（孔雀石/蓝铜矿/锡石砂矿）→ 破碎水洗（选矿雏形）→ 木炭还原炼铜（鼓风 1200 °C）→ 陶范铸造 → 青铜配比（Cu:Sn ≈ 9:1，硬度试错）→ 工具升级；玻璃：石英砂 + 钾碱 + 石灰，熔窑 1350–1450 °C → 玻璃珠/容器/**透镜 → 简易显微镜（观察酵母——"微生物"概念解锁）**；发酵：麦芽糖化酿酒 → 表面发酵制醋；油脂 + 碱 → 皂化盐析制肥皂；树皮单宁鞣革；铜蒸馏器 → 烈酒（蒸馏第一课）。
**里程碑**：① 青铜锭（硬度达标）；② 无气泡透明玻璃；③ 显微镜观察酵母；④ 醋与肥皂。
**硬核点**：硫化矿焙烧冒 SO₂（上风口意识）；锡稀缺（砂锡淘洗）；玻璃熔炼燃料压力；发酵杂菌酸败 → 引出灭菌概念。

### 阶段 2｜铁器时代：钢铁与火药（30–50 h）
**定位**：铁 = 设备与高压容器的物质前提；火药 = 采矿革命 + 硝化化学的起点。
**关键链**：磁石吸附探磁铁矿/赤铁矿露头 → 块炼炉（bloomery，1200–1300 °C）→ 海绵铁锻打除渣 → 熟铁；渗碳/淬火 → 钢（碳含量 0.2–0.8%，**火花鉴别法测碳**）；高炉（水车强鼓风 + 石灰石助熔，1500 °C）→ 生铁（~4% C）→ 铸铁器皿/管道；黄铁矿焙烧 → 硫磺 + 绿矾（阶段 3 制硫酸的原料）；硝土浸取（硝床微生物硝化）→ 硝石重结晶提纯（溶解度曲线第一课）；火药 KNO₃:S:C = 75:15:10（湿法研磨防爆）→ 爆破采矿；竖井采矿（支护/排水/通风）。
**里程碑**：① 高炉出铁（炉渣碱度控制）；② 钢（火花法碳含量合格）；③ 火药（配比验证）；④ 硝石重结晶纯度；⑤ 井下爆破。
**硬核点**：高炉结瘤/冻炉；矿井瓦斯（戴维安全灯火焰判 CH₄/CO₂——气体检测第一课）；火药研磨事故（湿磨规则）。

### 阶段 3｜化学革命：酸·碱·焦化（50–80 h）
**定位**：酸是湿法化学的钥匙，碱与酸配对诞生分析化学，焦化是有机化学之母。
**关键链**：
- **煤**：矿井深采 → 砖砌焦炉（副产回收：煤气照明、煤焦油、氨水）→ 焦炭（高炉燃料升级）。
- **硫酸**：绿矾干馏（曲颈甑）→ vitriol 油（实验室少量）；**铅室法**（黄铁矿焙烧 SO₂ + 硝石 NOₓ 循环催化 + 铅室吸收，产 65–78% 酸；铅来自方铅矿焙烧还原）。
- **盐酸/硝酸/王水**：岩盐 + 硫酸 → HCl 吸收；硝石 + 硫酸蒸馏 → 硝酸（曲颈甑冷凝）。
- **碱**：勒布朗法（NaCl + H₂SO₄ → 芒硝 + HCl↑；芒硝 + 石灰石 + 煤反射炉 → 黑灰 → 浸取结晶 → 纯碱；HCl 副产回收成盐酸/氯气）；**索尔维法**（焦炉氨水 + 石灰窑 CO₂ → NaHCO₃ → 煅烧，氨循环蒸氨回收）。
- **玻璃仪器**：硼砂（蒸发岩）→ 硼硅玻璃 → 吹制烧瓶/试管/李比希冷凝管/分液漏斗/滴定管；水银/酒精温度计（辰砂焙烧提汞）、托里拆利气压计（真空概念）。
- **分析第一课**：石蕊指示剂（地衣）→ 酸碱滴定（纯碱作基准物标定盐酸）→ 酸浓度定量。
- **漂白粉**：软锰矿 + 盐酸 → Cl₂（舍勒 1774）→ 石灰乳吸收（漂白粉 1799，纺织升级）。
- **银镜反应**：铅锌矿伴生银 → 吹灰法提银 → 硝酸银 → 托伦试剂（醛基检测第一课）。
**里程碑**：① 铅室硫酸（滴定验证 65%+）；② 索尔维纯碱（98%+）；③ 盐酸/硝酸标定；④ 玻璃仪器套装（吹制良品率）；⑤ Cl₂/漂白粉；⑥ 煤气管道照明。
**硬核点**：铅慢性中毒与酸雾腐蚀；Cl₂ 第一次毒气操作（湿毛巾防护教学）；玻璃吹制手感；焦炉调火（焦炭成熟度按挥发分判定）；索尔维氨损耗与蒸氨塔收率。

### 阶段 4｜工业革命：蒸汽·电力·合成氨（80–120 h）
**定位**：把"高压 + 催化 + 循环 + 净化"四大化工工程概念一次性教给玩家；合成氨是全游戏第一道总门槛。
**关键链**：
- **蒸汽机**（纽科门抽水 → 瓦特分离冷凝器 + **飞球调速器（负反馈第一课）**；铸铁气缸镗削 = 精密加工第一课；铆接锅炉 + 安全阀）→ 深井采煤/磨矿/鼓风全动力化；**蒸汽铁路**（大宗物流）。
- **电力诞生**：法拉第盘式 → 西门子自励直流发电机（蒸汽拖动）→ 弧光灯；伏打电堆 → 铅酸蓄电池（储能第一课）；电解水（霍夫曼电解器）；**电解精炼铜**（CuSO₄ 电解，阳极泥 → 金银铂钯回收链开启）。
- **焦油分馏**：煤焦油间歇蒸馏 → 轻油（苯/甲苯/二甲苯 BTX）、中油（萘/苯酚）、重油（蒽/沥青）——分馏与塔板概念。
- **硝化与染料**：混酸硝化苯 → 硝基苯 → 苯胺（铁粉 + 盐酸还原 → 水蒸气蒸馏提纯）；苯胺紫（苯胺 + 重铬酸钾氧化，Perkin 1856）；靛蓝（苯胺 → N-苯基甘氨酸 → 碱熔 → 吲哚酚氧化，Heumann 路线）。
- **炸药线**：油脂水解副产甘油（减压蒸馏需真空泵）→ 硝化甘油（混酸硝化，冰浴极致控温）→ 硅藻土吸收 → **达纳炸药**（"不稳定物稳定化"配方工程）；硝化棉 → 无烟火药；雷汞 → 雷管；TNT（甲苯三段硝化，温度梯度与定位选择性教学）；苦味酸。
- **接触法硫酸**（1831/1901）：黄铁矿沸腾炉（流态化第一课）→ 净化 → V₂O₅ 转化器（450 °C 多段换热——"平衡 vs 速率"最优温区教学）→ 98% 吸收；余热副产蒸汽（换热网络）。
- **合成氨（哈伯-博施，本阶段总 Boss）**：水煤气发生炉（焦炭 + 水蒸气间歇气化）→ 变换（Fe-Cr 催化）→ 脱硫（催化剂中毒教学）→ 加压水洗脱碳 → 空气燃烧除氧制 N₂ → 多级往复压缩机（蒸汽驱动，200–300 atm）→ 合成塔（Fe₃O₄-K₂O-Al₂O₃，450–500 °C）→ 氨冷凝分离 + **未反应气循环回路（循环工艺第一课）**。
- **下游**：奥斯特瓦尔德法硝酸（NH₃ + O₂ 铂铑网 900 °C）→ 硫酸铵/硝酸铵（化肥时代）；氨压缩制冷（冷链）；尿素（NH₃ + CO₂ 高压合成，Bosch-Meiser）。
**里程碑**：① 瓦特蒸汽机（调速器闭环稳定）；② 发电机 + 弧光灯；③ 电解精铜 99.9%；④ BTX 分馏（苯纯度以密度/折光判定）；⑤ 苯胺紫/靛蓝染色牢度；⑥ 达纳炸药 + 雷管爆破对比实验；⑦ 接触法 98% 硫酸；⑧ **合成氨稳定运行**（产量 + 氨滴定纯度——解锁"喂饱世界"成就）。
**硬核点**：锅炉超压爆炸（安全阀 + 表计）；压缩机 H₂ 泄漏（肥皂水检漏教学）；催化剂硫中毒（上游净化不彻底 → 换剂成本惩罚）；硝化温度失控；CO 中毒（氯化钯试纸检测）；铂网稀缺（贵金属回收循环）。

### 阶段 5｜电气化时代：氯碱·铝·空分（90–130 h）
**定位**：电把化学工业从"热驱动"推向"电驱动"；不锈钢与空分是此后一切高端化学的材质与气氛基础。
**关键链**：
- **电网**：汽轮机（帕森斯多级叶轮）+ 交流发电机 + 变压器（硅钢片）→ 全厂电动化（泵/搅拌/行车）。
- **电炉冶金**：电弧炉（石墨电极）→ 合金钢；铬铁矿 → 铬铁 → 不锈钢 304/316L（Cr₂O₃ 钝化膜耐蚀教学）；钨粉冶金（黑钨矿 → 仲钨酸铵 → H₂ 还原 → 烧结 → 钨丝白炽灯 + 硬质合金 WC-Co——粉末冶金第一课）。
- **氯碱**（隔膜法 → 离子膜法）：盐水精制（除 Ca/Mg）→ 电解 → Cl₂ + H₂ + NaOH；H₂ 供养合成氨/加氢，Cl₂ 养盐酸/漂白/氯化，NaOH 养造纸/皂化/氧化铝——**联产平衡第一课**。
- **氟化学**（最危险支线）：萤石 + 硫酸 → HF（塑料容器）→ 电解 KF·2HF → F₂（最毒气体）→ 氟利昂（→ 环保替代线）/ PTFE（塑料王衬里）/ Nafion 膜（离子膜法前置）。
- **铝**：铝土矿 → 拜耳法（NaOH 高压溶出 → 晶种分解 → 煅烧）→ 冰晶石（HF 合成）+ Al₂O₃ 电解（950 °C，碳阳极消耗——CO₂ 环保线 + 惰性阳极彩蛋）→ 航空/电缆/包装。
- **空分（林德，第二道总门槛）**：多级压缩 → 碱洗干燥 → 氨制冷预冷 → 节流膨胀（焦耳-汤姆逊教学）→ 双塔精馏 → **液氮/液氧/氩**。O₂ 供养转炉炼钢（碱性氧气顶吹 BOF：造渣除 P/S）与接触法；N₂/Ar 供惰性气氛（无水无氧操作的前置！）；液氮 = 低温平台（NMR/超导的前置）。
- **水泥**：回转窑 1450 °C 烧熟料（C₃S/C₂S 矿物相）+ 石膏粉磨 → 混凝土 → 大型基建（厂房/储罐/大坝水电）。
- **造纸**：硫酸盐法（NaOH + Na₂S 蒸煮，Na₂S 来自芒硝还原）→ 漂白（Cl₂ → ClO₂ 环保升级）→ 纸张（研究手册/滤纸量产）。
**里程碑**：① 交流电网输电；② 电弧炉不锈钢（盐酸/氯离子浸泡验证）；③ 氯碱隔膜法（尾气碱吸收安全达标）；④ HF/PTFE；⑤ 电解铝（电耗经济核算——铝厂选址水电旁，工业区位教学）；⑥ **空分双塔稳定出液氮/液氧**（N₂ 纯度 99.999% 燃烧试验验证）；⑦ 转炉炼钢（产量 ×10）；⑧ 回转窑水泥（基建跃升）；⑨ 造纸全链。
**硬核点**：Cl₂ 大规模泄漏（正压呼吸器）；HF 烧伤（葡萄糖酸钙急救教学）；F₂ 储运（蒙乃尔/镍容器材料知识）；空分塔碳氢富集爆炸（真实事故——分子筛前置吸附）；电解铝电耗规划；不锈钢冶炼 Cr 烧损控制。

### 阶段 6｜石油化工时代：炼油与高分子（110–150 h）
**定位**：把阶段 4 的四大概念工业化到极限；"副产平衡"成为核心解谜。
**关键链**：
- **石油**：构造勘探（背斜圈闭，露头 + 旋转钻井——钻井液需膨润土 + 重晶石）→ 采油（自喷 → 抽油机 → 注水 EOR）→ 集输。
- **炼油**：常压蒸馏（管式加热炉 + 常压塔回流比控制）→ 减压蒸馏（三级蒸汽喷射真空）→ 热裂化 → **催化裂化 FCC**（Y 型沸石水热合成 + 流化床提升管/再生器——流态化工程 + 积碳再生）→ 铂重整（Pt-Re 双金属，芳烃 + 高辛烷值 + 副产 H₂——氢平衡）→ 加氢精制（Co-Mo 脱硫 → H₂S → **克劳斯硫回收闭环**）→ 烷基化（航空汽油，HF/硫酸）→ 延迟焦化（石油焦 → 电极原料）。
- **蒸汽裂解**：石脑油 800–850 °C 管式炉（耐热合金管，毫秒停留 + 急冷废锅联产高压蒸汽）→ 深冷分离（五段压缩 + 分子筛干燥 + 冷箱 + 乙烯制冷循环）→ **聚合级乙烯 99.9%**。
- **高分子七条主链**：
  1. **PE**：LDPE（2000 atm 超高压自由基聚合——极限压力工程）+ HDPE/LLDPE（Ziegler-Natta 1953：TiCl₄/AlEt₃，有机铝自燃需无水无氧——惰性气氛教学）。
  2. **PP**（Natta 等规聚合——立构规整性第一次亮相）。
  3. **PVC**（乙烯氯化 → EDC 裂解 → VCM + 氧氯化回收 HCl——**氯平衡闭环**；悬浮聚合，PVA 分散剂）。
  4. **PS/ABS**（乙苯分子筛烷基化 → 脱氢；丙烯氨氧化 Sohio 法制丙烯腈）。
  5. **PET**（对二甲苯：重整/异构化/甲苯歧化（分子筛择形催化）→ **模拟移动床吸附分离 Parex**——同分异构体分离工程巅峰；PTA 氧化（醋酸体系 Co-Mn-Br 催化，钛材防腐）；环氧乙烷 Ag 催化 → 乙二醇 → 缩聚 → 熔纺涤纶）。
  6. **尼龙 66**（己二腈：丁二烯 + HCN 安氏法剧毒链；己二胺雷尼镍加氢；己二酸硝酸氧化；尼龙盐缩聚）/ 尼龙 6（环己酮肟贝克曼重排）。
  7. **合成橡胶**（丁苯 SBR 乳液聚合；顺丁溶液聚合——丁基锂需金属锂：盐湖提锂 + 熔盐电解；轮胎 = 炭黑炉法 + 钢丝帘线 + 硫化体系——促进剂 MBT 需 CS₂）。
- **三大材料/日化**：环氧树脂（双酚 A + 环氧氯丙烷——甘油法绿色路线可选）；聚氨酯（光气 + 苯胺 → MDI/TDI——剧毒全封闭工艺；HPPO 法制环氧丙烷 + 蒽醌法双氧水——绿色线）；LAS 洗涤剂（煤油分子筛脱蜡 → 烷基苯 → SO₃ 膜式磺化——支链 ABS 禁用事件 → 直链）。
- **合成气平台（现代化工之母）**：天然气蒸汽重整 SMR / 煤气化（空分 O₂ 大客户）→ 甲醇（Cu/ZnO 催化）→ 甲醛/乙酸（铑羰基化 Monsanto——贵金属均相催化）/MTO（甲醇制烯烃 SAPO-34——**煤化工 vs 石油化工双路线分支**）；天然气硫回收；大型合成氨装置（化肥产能 ×10）。
**里程碑**：① 炼油联合装置（汽柴芳达标）；② 聚合级乙烯（深冷分离运行）；③ HDPE/PP（熔融指数 MFR 测定）；④ PVC 氯平衡闭环；⑤ **PET 全链：从原油到布料**；⑥ 尼龙 66（HCN 剧毒工艺安全达标）；⑦ 轮胎（车辆解锁）；⑧ 洗涤剂/环氧/聚氨酯三件套；⑨ 合成气平台（甲醇/乙酸）；⑩ 环保三成就（脱硫/无铅/可降解洗涤剂）。
**硬核点**：烃类爆炸极限（LEL 报警仪表第一课）；FCC 积碳与重整水氯平衡；LDPE 超高压联锁；HCN/光气全封闭 + 应急中和；**物料衡算解谜**（氯平衡/氢平衡/芳烃平衡/蒸汽平衡——装置间调度最优化）；排放在线监测（CEMS）；放大效应（中试 → 工业收率折减，需反应工程重新调优）。

### 阶段 7｜精细化工时代：医药·手性·仪器（130–180 h）
**定位**：平台原料变成高价值分子；核心玩法从"连续流程"转向"合成-纯化-表征"三步循环。
**关键链**：
- **单元反应工具箱**（每类一个教学链 + 标准品验证）：卤化（氯苯亲电/苄氯自由基/NBS 烯丙位选择性）；硝化/磺化/傅克（定位规则教学）；氧化（KMnO₄ 电解法、铬酸——六价铬环保线、H₂O₂ 蒽醌法、臭氧——无声放电）；还原（雷尼镍 1926 多孔结构、Pd/C——阳极泥贵金属冶金：王水溶铂族分离序列、NaBH₄——金属钠电解 + 无水无氧、LiAlH₄——金属锂、伯奇还原——液氨处理）；C-C 成键（格氏试剂 1912 诺奖——无水乙醚 + Schlenk 惰性操作、醇醛缩合、Wittig 1979 诺奖——黄磷链、傅克酰基化——氯化亚砜）；重氮化（0–5 °C 冰浴控温 + 偶联染料全色系 + 桑德迈尔 + 费歇尔吲哚合成）；保护基（缩酮/苄基/TBS——氯硅烷链）。
- **手性化学**：天然手性源（葡萄酒酒石酸钾 → 酒石酸——巴斯德 1848 拆分复刻；谷氨酸发酵；松节油萜烯）；**自制旋光仪**（钠灯——金属钠蒸汽光谱 + 偏光片——海带提碘 + PVA 拉伸）；拆分（结晶拆分/脂肪酶酶法拆分——生物催化第一课）；**不对称催化**：Sharpless 环氧化（Ti(OiPr)₄——海绵钛 Kroll 法链 + 酒石酸二乙酯 + TBHP——过氧化物安全，ee>90%）、Noyori 氢化（BINAP-Ru——联萘偶联拆分）、MacMillan 有机催化（2021 诺奖，无金属手性催化——绿色化学顶点）；**手性 HPLC 柱自制**（淀粉酶环化环糊精/纤维素衍生物涂敷硅胶）。
- **药物四经典**：阿司匹林（苯酚磺化碱熔 → 水杨酸 Kolbe-Schmitt 高压羧化 → 醋酐酰化 → 压片制剂）；扑热息痛（对硝基氯苯 → 对硝基苯酚水解 → 还原 → 酰化）；磺胺（乙酰苯胺保护氨基 → 氯磺化 → 氨解 → 去保护——保护基第一课）；**青霉素链**（土壤/空气采样培养青霉 → 琼脂平板抑菌圈筛选——海带提琼脂海洋链 → 紫外线/X 射线诱变高产菌株（汞灯链）→ 深罐通气发酵（无菌空气过滤 + pH 自动控制——仪表自动化第一次实战）→ 乙酸丁酯萃取 pH 摆动 → 结晶青霉素 G 钾盐 → 固定化青霉素酰化酶制 6-APA → 半合成阿莫西林（酶法手性侧链））。
- **维生素 C**（淀粉酶解 → 葡萄糖 → 山梨醇 Ni 加氢 → 醋酸菌发酵山梨糖 → 双丙酮保护 → 次氯酸氧化 → 内酯化；碘量法滴定验证还原性；彩蛋：中国两步发酵法路线）。
- **分析仪器全谱**（每台一条制造链，见 2.4）：pH 计（玻璃电极 + 甘汞参比 + 电子管电位计）→ 旋光仪 → 折光仪/熔点仪 → UV-Vis（光栅刻划 + 氢灯 + 光电管——硒/铯稀有金属）→ GC（TCD 钨丝/FID 氢焰 + 硅藻土担体——炼油石化全程依赖）→ HPLC（蓝宝石柱塞高压泵——焰熔法刚玉单晶 + C18 键合硅胶 + 六通阀）→ MS（电子轰击 + 四极杆 + 高真空扩散泵）→ IR（KBr 盐片单晶）→ **NMR**（液氦超导磁体 + 铌钛线 + 射频脉冲 + FFT 计算机——通关必备）→ XRD（X 光管：高真空 + 高压电源 + 铜靶——超导真结局必备）。
- **GMP 质量体系**：洁净车间（HEPA 层流 + 风淋 + 粒子计数）+ 验证批记录——药品通关前置。
**里程碑**：① 合成工具箱全解锁（每类标准品验证收率 + 纯度）；② 阿司匹林/扑热息痛/磺胺三经典；③ 青霉素发酵 → 半合成阿莫西林（生物化工里程碑）；④ 维生素 C 全合成；⑤ 旋光仪 + 巴斯德拆分复刻（手性概念诞生）；⑥ Sharpless/Noyori 催化 ee 验证（紫杉醇技术储备）；⑦ GC/HPLC/MS/IR/UV 五件套自造；⑧ NMR 开机出谱；⑨ XRD 物相鉴定；⑩ 偶氮/活性染料全色系（纺织现代化）；⑪ 人工淀粉合成支线（可选，见 [side-quest-artificial-starch.md](side-quest-artificial-starch.md)）。
**硬核点**：无水无氧失败事故（格氏/丁基锂遇水）；过氧化物爆炸（乙醚/THF 蒸馏前 KI 试纸）；金属钠处置规范；发酵染菌整罐报废（灭菌验证 + 生物指示剂）；慢性毒物强制通风橱 + 丁基橡胶 PPE；贵金属催化剂回收闭环；仪器校准与标准品管理；手性 ee% 不达标 → 产物报废（光学纯度经济惩罚）。

### 阶段 8｜电子材料时代：硅·芯片·自动化（100–140 h，与 7 可并行）
**定位**：把"纯度"推到终点（9N–12N）；DCS 是红石的正式继承者。
**关键链**：
- **超纯水**：砂滤 → 活性炭 → 离子交换（苯乙烯-二乙烯苯树脂）→ 反渗透（醋酸纤维素/聚酰胺膜）→ EDI 电去离子 → 18.2 MΩ·cm 电阻率验证——电子工业血液。
- **硅链**：冶金硅（电弧炉）→ 三氯氢硅（HCl 流化床 + 多级精密精馏）→ 西门子还原（硅棒热分解，9N–11N 多晶硅）→ **CZ 直拉单晶**（石英坩埚 + 石墨热场 + 氩气；位错/氧含量控制；硼磷砷掺杂）→ 区熔提纯（高频感应，12N；锗 13N——闪锌矿烟尘 → GeCl₄ 精馏水解还原）；切片（HPHT 人造金刚石微粉金刚线——**高压设备第一课，真结局前置**）→ 磨抛（CMP 胶体 SiO₂/氧化铈抛光液）。
- **电子特气**：SiH₄（硅化镁液氨法）、PH₃/AsH₃（剧毒极致管理）、NF₃（氟链再就业）、CF₄/SF₆（等离子刻蚀气体）；高纯气纯化（催化脱氧 + 吸附 + 膜，5N–7N）。
- **电子元器件**：无源件（钛酸钡陶瓷电容/铝电解电容/漆包线——聚酯绝缘漆）→ **真空管**（钨丝阴极 + 钼栅极 + 扩散泵高真空 + 钡吸气剂——电子学第一课）→ 晶体管（锗点接触 1947 历史复刻 → 扩散/平面工艺：氧化-光刻-扩散三循环）→ **集成电路**（掩模制版——铬玻璃；光刻胶：酚醛-重氮萘醌 g/i 线 → 化学放大胶 PHS + PAG 光致产酸剂 248 nm KrF → 193 nm ArF 聚甲基丙烯酸酯；**准分子激光**——Kr/F₂、Ar/F₂ 稀有气体卤化物放电；显影 TMAH 季铵碱；刻蚀：湿法 HF/HNO₃ → 干法 RIE 等离子体（射频 13.56 MHz + MFC 质量流量计）；掺杂：热扩散 → **离子注入**（离子源 + 100 kV 加速 + 磁分析 + RTP 退火）；薄膜：蒸发/溅射/CVD/ALD（原子层沉积彩蛋）；互连：铝 → 铜大马士革（电镀 + CMP 再就业））。
- **计算机与控制**：继电器梯形图（布尔逻辑教学）→ 真空管计算机（简化教学机）→ 晶体管逻辑门 → 集成电路 → **PLC**（4–20 mA 输入 + 继电器/调节阀输出 + 梯形图编程——真实工业语言）→ **DCS 中央控制室**（CRT 操作站 + 组态 + **PID 整定**——阶跃响应实验 + 稳定性判据——控制论教学）→ 老厂自动化改造任务线（逐个装置升级：产能/收率/安全提升——长线乐趣）。
- **过程仪表全系列**：热电偶/热电阻、压力/差压变送器、孔板/电磁/科里奥利流量计、液位（浮子/差压/雷达/超声）、在线气体分析（热导/顺磁氧/NDIR/在线 GC）、可燃有毒报警（催化燃烧/电化学）——阶段 5–7 工厂的"眼睛和手"。
- **激光**：红宝石激光 1960（焰熔法红宝石 + 氙灯——空分稀有气体提纯 + 镀银谐振腔）、CO₂ 激光、准分子、Nd:YAG（稀土单晶提拉）。
**里程碑**：① 超纯水 18.2 MΩ·cm；② 电子级酸/气（ppb 验证）；③ CZ 单晶硅锭（无位错 + 电阻率达标）；④ 真空管放大电路；⑤ **第一块集成电路**（光刻全流程多层对准）；⑥ PLC 上线 + 合成氨装置 DCS 改造（黑灯工厂成就）；⑦ 准分子激光 193 nm；⑧ 离子注入 + 干法刻蚀全谱；⑨ 在线仪表全系列（过程分析化学）；⑩ HPHT 人造金刚石（真结局前置）。
**硬核点**：洁净度 vs 良率（尘埃随机事件 → 芯片报废经济惩罚）；特气泄漏（自燃/剧毒——钢瓶柜 + 双检测 + 应急喷淋）；CZ 断晶/位错（温场扰动技能深度）；射频/高压电击；真空漏率（氦质谱检漏仪——提氦链联动）；PID 整定失败 → 装置振荡停车（控制论深度）；**机床精度等级决定光刻对准误差**（工业母机概念：精密磨床/坐标镗床依赖合金钢 + 硬质合金 + 磨料）。

### 阶段 9｜终局：紫杉醇与超导真结局（100–150 h）
**主线：紫杉醇全合成/半合成**
1. **原料**：种植红豆杉（生长周期农业规划）→ 针叶干燥粉碎 → 醇浸提（10-DAB 含量约 0.1%——大规模浸提工厂）→ 液液萃取 → 柱层析 → 结晶（10-DAB ≥ 95%）。
2. **侧链（不对称催化实战）**：苯甲醛 + 醋酐 Perkin 缩合 → 肉桂酸酯 → **Sharpless 不对称双羟化**（K₂OsO₄——锇剧毒挥发安全链 + (DHQD)₂PHAL——金鸡纳树皮天然生物碱）→ (2R,3S)-二醇 ee ≥ 95% → 环化/酰胺化（苯甲酰氯）。
3. **对接**：10-DAB C7 位 TBS 保护（TBSCl + 咪唑）→ C13 位选择性酯化（LDA/丁基锂低温无水无氧——空间位阻选择性教学）→ 去保护（氟化氢吡啶）。
4. **精制**：制备柱层析 → 结晶（乙腈/乙酸乙酯）→ 六项表征验收（见 1.1）。
5. **中试放大**：克级 → 公斤级逐级放大（混合/传热限制收率折减——反应工程考试）+ GMP 车间认证 + 连续 3 批稳定 → **通关**。

**真结局：高压镍基超导（通关后追加）**
- **前置**：YBCO（稀土萃取级联分离钇——TBP/P507 混合澄清槽逆流萃取计算；固相烧结 900–950 °C + 氧退火控氧；液氮迈斯纳悬浮——1987 复刻）→ SmFeAsOF（砷/氟剧毒链 + 真空密封石英管 1150 °C；液氦悬浮——2008 复刻）。
- **高压技术**：六面顶压机（超高压液压 + 碳化钨顶锤大尺寸烧结）→ HPHT 人造金刚石单晶（温度梯度法）→ 金刚石对顶砧（铼垫片——辉钼矿烟尘提铼 Re₂O₇ 升华捕集）→ 压力标定（红宝石荧光位移——激光链联动）→ ≥14 GPa。
- **测量与判定**：高压原位四探针（铂丝微电极 + 氧化铝绝缘涂层）→ 电阻 ~80 K 骤降 ≥3 个数量级 + 原位抗磁信号 → 数据独立复现 3 次（"同行评议"关卡——排除接触电阻/杂质相假象）→ 真结局 CG + 现实对照年表（1831–2023）。

## 4. 全流程内在逻辑

### 4.1 七条贯穿线
| 线 | 阶梯 | 决定什么 |
|---|---|---|
| 温度 | 800°C 陶 → 1200°C 玻璃/青铜 → 1500°C 生铁 → 2000°C 电石 → 3000°C 电弧炉 | 材料 → 设备 → 反应可行域 |
| 压力 | 常压 → 10 atm 蒸汽 → 300 atm 合成氨 → 2000 atm LDPE → GPa 级 DAC | 平衡移动与高压合成/研究 |
| 纯度 | 90% 选矿 → 99% 冶金 → 99.9% 化学纯 → 9N 电子级 → 12N 单晶 | 下游工艺与产品档次 |
| 能量 | 人力 → 水风 → 蒸汽 → 电 → 等离子/激光 | 可用单元操作（蒸发 vs 电解 vs 刻蚀） |
| 碳源 | 无机盐 → 煤焦油（芳烃）→ 石油/天然气（烯烃/合成气）→ 生物质/发酵 → 精细分子 | 分子复杂度上限 |
| 分析 | 滴定 → 物性 → 色谱 → 光谱 → 波谱（NMR/MS/XRD） | 是否有"知识"（无表征 = 无进度） |
| 控制 | 人工 → 机械凸轮 → 气动 → 电气 → 数字 DCS | 能否放大与自动化 |

### 4.2 自举逻辑（每一阶段的产物 = 下一阶段的原料/工具）
```
火·陶 ──► 温度/容器 ──► 青铜/玻璃 ──► 金属工具 + 观察手段
玻璃 + 铁 ──► 曲颈甑/高炉 ──► 酸(硫酸/硝酸/盐酸) + 焦化(苯/氨/焦炭)
酸 + 碱 + 滴定 ──► 分析化学 ──► 硝化/染料/炸药 + 合成氨
蒸汽 + 电 ──► 压缩机/电解/电炉 ──► 高压反应 + 氯碱/铝/空分(液氮)
空分 + 高压 + 催化 ──► 惰性气氛 + 石化 ──► 乙烯/芳烃/合成气
平台原料 + 手性催化 ──► 药物分子 ──► 紫杉醇(主线)
电子级纯化 + 单晶 ──► 仪器(NMR/XRD) + DCS ──► 超导研究(真结局)
```
关键闭环示例：**液氮**（阶段 5 空分）→ NMR 冷却（阶段 7）→ 紫杉醇结构验证（主线）；液氮 → YBCO 悬浮验证 → 液氦（提氦 + 液化）→ 铁基/镍基超导（真结局）。**硫酸**（阶段 3）→ 萤石制 HF（阶段 5）→ 氟化氢吡啶去保护（紫杉醇）；**铂**（阶段 4 阳极泥）→ 铂网制硝酸 → 重整催化剂 → 铂丝电极（超导测量）。

### 4.3 为什么必须是这个顺序（五重可行性）
1. **热力学可行性**：温度梯度决定反应能否发生——不能先做电炉（需电），必须先爬窑炉阶梯。
2. **材料可行性**：反应器材质决定条件上限——没有不锈钢就没有浓硝酸工业，没有 PTFE 就没有氟化学，没有钛就没有氯碱阳极。
3. **检测可行性**：没有滴定就没有酸的定量，没有色谱就没有纯度概念，没有 NMR 就没有结构证明——知识由仪器解锁。
4. **经济可行性**：规模决定是否"养得活"——合成氨先有化肥才有多余粮食养发酵工业；先有石化副产品（甘油/丙酮）才有下游日化。
5. **安全可行性**：每一级危险物（Cl₂ → HF/F₂ → 光气/HCN → 砷烷/硅烷）都有对应防护技术与教训先例——安全链条本身就是科技树。

**一句话总结：这个流程 = 人类化学工业 200 年历史的压缩重放，因为历史顺序就是"现有基建能支撑的下一步"的最优解，天然符合从零自举的生存逻辑。**

### 5.2 重做

- **食物与营养**：碳水/蛋白/脂肪/维生素四维，长期缺乏 → 真实病症（坏血病需维生素 C——与阶段 7 化学链联动）；保藏链：腌制 → 罐藏（镀锡板，冶金链）→ 冷链（氨制冷）。

- **村民交易**：保留为地区特产贸易（硝石/硼砂/金鸡纳树皮等地域资源），删除魔法交易。

### 5.3 生活-农业-轻工配套线（每一条都反哺化工）
农业（淀粉/糖/油料/纤维/红豆杉/金鸡纳树）→ 制糖（石灰-碳酸法清净 → 结晶精炼）、榨油（油脂 → 肥皂/甘油/脂肪酸/生物柴油）；畜牧（皮革鞣制、骨炭、微管蛋白提取材料）；林业（木炭/造纸/松脂）；渔业/海洋（琼脂、海带提碘、海胆卵——紫杉醇活性实验！）；制盐（海盐/岩盐/盐湖）。

## 6. 硬核挑战与挫败感管理

**挑战来源**：事故系统（爆炸/中毒/腐蚀/辐射，操作失误毁设备 + 永久死亡惩罚）；催化剂中毒/积碳（需巡检再生）；收率经济（物料衡算失衡 → 成本爆炸）；环保红线（污染区块 → 减产 + 治理成本）；长周期项目（菌种多代诱变筛选、红豆杉生长、单晶拉制）；手性/纯度不达标 → 整批报废；真实死亡惩罚（携带物损失 + 厂区需重建局部）。

**挫败感管理（保持"难但不恶心"）**：
- 研究手册全程记录已验证的方程式与工艺参数（像真实实验记录本），失败有据可查；
- 危险反应提供"安全检查清单"机制（真实化工的作业票制度），事故前有明确预警而非随机惩罚；
- 中试/工业装置可存"工艺包"（调试好的参数存档），重复生产可一键复现——放大的苦只吃一次；
- 长周期项目可并行进行（红豆杉生长期间做超导线）；
- 里程碑检测免费重试，仅消耗试剂——练操作成本低，上装置成本高。

## 7. 实现路线图（工程建议）

**核心模块**（全部数据驱动，Fabric 1.21.1，物品用 Data Components 存纯度/杂质/ee%）：
1. 物质注册表（真实物性：沸点/熔点/密度/毒性/爆炸极限，JSON 数据）；
2. 反应引擎（原料 + 条件 → 产物 + 收率 + 副产物）；
3. 设备系统（材质/耐温/耐压/容量/腐蚀）；
4. 流体管道（压力-流量简化模拟）与能量（机械/蒸汽/电换算）；
5. 分析引擎（谱图生成/比对——NMR 用简化的特征峰列表）；
6. 地质（矿床/品位）与安全（毒/爆/辐射）；
7. 生物（发酵动力学简化：菌种代数 + 产量分布）。

**参考模组**：TerraFirmaCraft（生存/地质/温度）、GregTech（工业链严谨度）、Rockhounding: Chemistry（真实化学反应）、Create（机械传动/流体手感）。

**开发阶段（每阶段一个可玩垂直切片）**：
0. 核心引擎 + 温度/流体 → 1. 石器–铁器（阶段 0–2）→ 2. 酸碱 + 玻璃仪器（阶段 3）→ 3. 蒸汽 + 焦化 + 合成氨（阶段 4）→ 4. 电 + 空分 + 氯碱（阶段 5）→ 5. 石化 + 高分子（阶段 6）→ 6. 精细 + 仪器（阶段 7）→ 7. 电子 + 自动化（阶段 8）→ 8. 终局（阶段 9）。
