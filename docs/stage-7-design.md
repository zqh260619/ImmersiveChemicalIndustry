## 1. 设计定位：本阶段要教的六个"终身技能"

1. **合成工具箱**——卤化、硝化、磺化、傅克、氧化、还原、格氏、Wittig、重氮化、保护基；每类一个教学链 + 标准品。
2. **分离纯化**——蒸馏、结晶/重结晶、萃取、TLC/柱层析、HPLC；"合成决定上限，纯化决定下限"。
3. **表征**——熔点、旋光、UV、IR、GC、HPLC、MS、NMR、XRD；没有表征就没有"结构"，也没有"知识"。
4. **手性**——对映体、ee、旋光仪、手性拆分、不对称催化；同一分子不同手性可以是药也可以是毒。
5. **生物催化**——菌种筛选/诱变、发酵、固定化酶；6-APA 是化学-生物杂交的经典。
6. **质量体系**——GMP、洁净车间、验证批、记录；药不是"做出来"就行，要"证明每一批都一样"。

## 2. 开局与世界生成

### 2.1 出生点保障

阶段 7 的精细化工区保证：

- **金鸡纳树**（热带，奎宁/DHQD 配体）、**地衣**（石蕊）、**海带/石花菜**（碘/琼脂）、**硅藻土**（过滤/色谱担体）；
- **硼砂/石英/萤石**（光学与玻璃仪器）、**铂族**（阶段 4 阳极泥）、**镍/铬/钼**（合金设备）；
- 煤/油/气（平台原料）、盐（试剂）、石灰石（CO₂/钙）。

### 2.2 原版内容调整（本阶段生效范围）

- 试剂瓶/容量瓶/滴定管等玻璃仪器为独立物品；试剂带浓度/纯度/ee 质量属性；
- 洁净车间（HEPA/风淋/正压）为可建造结构；
- 仪器（GC/HPLC/IR/MS/NMR/XRD）为多方块设备，需配套气体/电力/冷却；
- 红石系保持移除；自动化靠仪表与继电器（阶段 8 升级 DCS）。

### 2.3 气候与季节

- 发酵温度随季节波动（需恒温车间）；冬季冷却水温度低有利于深冷；
- 热带植物（金鸡纳/红豆杉）生长周期长，需种植园规划；
- 溶剂挥发与通风：夏季 VOC 风险高。

## 3. 核心机制

### 3.1 单元反应工具箱

| 反应 | 典型条件 | 教学产物 |
|---|---|---|
| 卤化 | Cl₂/FeCl₃（亲电）、Cl₂/光（自由基）、NBS（烯丙位） | 氯苯、苄氯、溴代物 |
| 硝化/磺化/傅克 | 混酸 50–55 °C、发烟硫酸、AlCl₃ | 硝基苯、苯磺酸、烷基苯 |
| 氧化 | KMnO₄、铬酸、H₂O₂、臭氧、空气催化 | 苯甲酸、己二酸、醛→酸 |
| 还原 | Fe/HCl、雷尼镍、Pd/C、NaBH₄、LiAlH₄、Na/NH₃ | 苯胺、醇、脱保护 |
| C–C 成键 | 格氏（无水乙醚）、醇醛缩合、Wittig（磷叶立德）、傅克酰基化 | 醇、烯烃、酮 |
| 重氮化 | 0–5 °C、NaNO₂/HCl；偶联/桑德迈尔 | 偶氮染料、卤代芳烃 |
| 保护基 | 缩酮、苄基、TBS | 多步合成的"临时锁" |

### 3.2 分离纯化

- 蒸馏（简单/分馏/减压/水蒸气）、结晶/重结晶（溶解度曲线）、萃取（分配系数）、TLC（Rf）、柱层析（硅胶）、HPLC（C18/手性柱）；
- 纯度是质量属性：99.0%/99.5%/99.9%/99.99% 对应不同下游（试剂/药用/电子级）；
- "合成-纯化-表征"循环：不合格 → 重结晶/重蒸/换条件。

### 3.3 表征与知识闸门

| 仪器 | 信息 | 检出限/误差（本阶段） |
|---|---|---|
| 熔点仪 | 纯度/晶型 | ±0.5 °C |
| 旋光仪 | 手性/ee | ±0.5° |
| UV-Vis | 共轭/浓度 | ppm 级 |
| IR | 官能团 | 4000–400 cm⁻¹ |
| GC | 挥发性组成 | ppm 级 |
| HPLC | 纯度/含量 | 0.1% 级 |
| MS | 分子量/碎片 | EI 70 eV，四极杆 |
| NMR | 结构（¹H/¹³C） | 600 MHz = 14.1 T，液氦 4.2 K |
| XRD | 物相/晶型 | Cu Kα 1.5406 Å |

- 未表征 = 未知：产物只显示"未检定"，做仪器分析后才写入手册并解锁配方；
- 谱图由物质定义 + 质量生成特征峰；仪器等级决定噪声/分辨率。

### 3.4 手性

- 天然手性源：酒石酸（葡萄酒石）、氨基酸（发酵）、萜烯（松节油）、奎宁（金鸡纳树皮）；
- 拆分：酒石酸盐结晶拆分（Pasteur 1848）、酶法拆分（脂肪酶）；
- 不对称催化：Sharpless 环氧化（Ti(OiPr)₄ + DET + TBHP，−20 °C，ee >90%）、Noyori 氢化（BINAP-Ru，1–10 MPa H₂，ee >99%）、MacMillan 有机催化（亚胺离子，无金属）；
- 手性 HPLC 柱：环糊精/纤维素衍生物涂敷硅胶；ee 不合格 → 产物报废。

### 3.5 生物催化

- 菌种：产黄青霉（青霉素）、醋酸菌（山梨糖）、黑曲霉（柠檬酸）、谷氨酸棒杆菌（味精）；
- 发酵：25–28 °C、pH 6.0–7.0、5–7 天、通气 1–1.5 vvm、灭菌 121 °C/20 min；
- 提取：pH 摆动萃取（青霉素 → 乙酸丁酯）、结晶；
- 固定化酶：青霉素酰化酶 → 6-APA（pH 8、37 °C）；酶法手性拆分（阿莫西林侧链）。

### 3.6 质量体系（GMP）

- 洁净车间：HEPA（99.97%）、正压、风淋、粒子计数；A/B/C/D 级对应无菌/洁净区；
- 验证批：连续 3 批、质量指标一致、记录完整；
- 清洁验证/交叉污染/留样；放行前必须"数据完整"。

### 3.7 安全

- 致癌/剧毒：苯、铬（VI）、肼、叠氮化物、光气、HCN；
- 无水无氧：格氏/丁基锂/NaH；过氧化物（乙醚/THF）检测；
- 高压氢/液氨/液氦；辐射（若有）；废液分类处理。

## 5. 工艺链详细设计

### 5.1 合成工具箱（10–14 h）

每类反应一个小教学链（原料 → 反应 → 后处理 → 纯化 → 表征）；标准品验证收率/纯度；重点：硝化定位、重氮化低温、格氏无水、保护基正交。

### 5.2 药物四经典（8–10 h）

- 阿司匹林（1899）：苯酚 → 水杨酸（Kolbe-Schmitt 高压羧化）→ 乙酰水杨酸（醋酐，85–90 °C，H₂SO₄ 催化，收率 85–90%）→ 重结晶（mp 135–136 °C）→ 压片；
- 扑热息痛：对硝基氯苯 → 对硝基苯酚 → 还原 → 乙酰化 → 重结晶（mp 169–170 °C）；
- 磺胺（1932）：苯胺 → 乙酰苯胺（保护）→ 氯磺化 → 氨解 → 水解去保护（mp 165 °C）；
- 青霉素：见 5.3。

### 5.3 青霉素链（10–14 h）

土壤/空气采样 → 平板筛选（抑菌圈）→ 紫外线/亚硝基胍诱变高产株 → 发酵（产黄青霉，25–28 °C、pH 6.0–7.0、5–7 天、1–1.5 vvm）→ 过滤 → 乙酸丁酯萃取（pH 摆动）→ 结晶青霉素 G 钾盐 → 固定化青霉素酰化酶（pH 8、37 °C）→ 6-APA → 阿莫西林（对羟基苯甘氨酸侧链，酶法拆分）。

### 5.4 维生素 C（8–10 h）

葡萄糖 → 山梨醇（Ni 催化加氢，100–140 °C、5–10 MPa）→ L-山梨糖（醋酸菌，pH 4–6、30–35 °C）→ 双丙酮保护 → KMnO₄ 氧化 → 2-酮-L-古龙酸 → 内酯化 → 维生素 C（mp 190–192 °C）；碘量法滴定验证还原性；彩蛋：中国两步发酵法。

### 5.5 手性化学（10–14 h）

酒石酸钾（葡萄酒石）→ 酒石酸 → 拆分实验（Pasteur 复刻）→ 旋光仪（钠灯）→ ee 测定；Sharpless 环氧化（−20 °C，ee >90%）→ 手性 HPLC 验证；Noyori 氢化（BINAP-Ru，ee >99%）；MacMillan 有机催化（ee 验证）；手性柱自制（环糊精/纤维素涂敷）。

### 5.6 分析仪器全谱（16–20 h）

pH 计（玻璃电极）→ 电导率 → UV-Vis（光栅/光电管）→ IR（KBr 压片）→ GC（TCD/FID，硅藻土担体）→ HPLC（蓝宝石柱塞泵、C18 柱、UV 检测器）→ MS（EI/四极杆/高真空）→ **NMR**（液氦超导磁体 14.1 T、射频脉冲、FFT 计算机）→ XRD（X 光管、铜靶、布拉格定律）；每台仪器一条制造链，校准用标准品。

### 5.7 GMP 与洁净车间（6–8 h）

HEPA/正压/风淋/粒子计数 → 洁净区（A/B/C/D）→ 无菌操作验证（培养基灌装）→ 连续 3 批验证 → 批记录/留样/放行；为阶段 9 的紫杉醇中试做准备。

## 7. 里程碑与阶段出口

**十项必需（研究手册逐条记录）：**

1. **合成工具箱**：每类反应一个标准品（收率+纯度）；
2. **阿司匹林/扑热息痛/磺胺**：三经典合成 + 熔点/纯度合格；
3. **青霉素**：发酵 → 提取 → 结晶；6-APA → 阿莫西林（生物催化）；
4. **维生素 C**：全合成 + 碘量法验证；
5. **手性拆分**：酒石酸拆分 + 旋光仪 ee 测定（Pasteur 复刻）；
6. **不对称催化**：Sharpless 或 Noyori，ee >90% 验证；
7. **分析五件套**：UV/IR/GC/HPLC/MS 自造并通过校准；
8. **NMR**：开机出谱、¹H/¹³C 结构确认（**阶段 Boss**）；
9. **XRD**：物相鉴定（超导/矿石/晶型）；
10. **GMP**：洁净车间 + 连续 3 批验证。

**出口任务「硅的召唤」**：用自制仪器验证一批 ≥99.99% 的试剂；建成 Class 1000 级洁净间；研究手册解锁阶段 8："纯度没有上限。"

## 8. 挑战与事故清单

| 事故 | 触发 | 后果 |
|---|---|---|
| 无水无氧失败 | 格氏/丁基锂遇水/氧 | 反应失败、起火 |
| 过氧化物爆炸 | 乙醚/THF 蒸馏 | 爆炸；KI 试纸检测 |
| 重氮盐分解 | 温度过高/干燥 | 爆炸；0–5 °C 严格控温 |
| 剧毒/致癌暴露 | 苯、铬(VI)、肼、光气 | 慢性/急性中毒；通风/PPE |
| 发酵染菌 | 灭菌不彻底 | 整罐报废 |
| 手性不达标 | 催化选择性差 | 产物报废（ee 不合格） |
| NMR 失超 | 液氦耗尽/磁体故障 | 设备损毁；失超保护 |
| 洁净室污染 | 粒子超标 | 批次报废 |
| 废液污染 | 有机/重金属废液 | 环保处罚 |

## 10. 实现要点（技术）

- **反应引擎**：单元反应模板（温度/配比/催化剂/时间 → 收率/选择性）；副产物与杂质生成；
- **纯化**：结晶/蒸馏/萃取/色谱的分离度与收率模型；纯度回写质量组件；
- **表征**：仪器读取质量组件 → 生成谱图/数据；未分析 = 未知；校准/误差；
- **手性**：ee 作为独立质量属性；不对称催化条件 → ee 模型；手性柱分离；
- **生物催化**：发酵（温度/pH/溶氧/时间）、菌种诱变（多代筛选）、固定化酶；
- **GMP**：洁净度（粒子数）→ 批次合格率；验证批记录；
- **数据驱动**：反应条件、仪器参数、谱图生成规则 JSON 化。
