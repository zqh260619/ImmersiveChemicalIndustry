## 1. 设计定位：本阶段要教的六个"终身技能"

1. **超纯与洁净**——18.2 MΩ·cm 的水、ppb 级金属杂质、ISO 1–5 级洁净室；"纯度没有上限"。
2. **单晶生长**——CZ 直拉、籽晶、提拉速度、掺杂、位错/氧含量；晶体缺陷是器件杀手。
3. **微纳加工**——光刻（涂胶/曝光/显影）、刻蚀、掺杂、薄膜；图形从微米到纳米。
4. **真空与等离子体**——涡轮泵/干泵、MFC、RF 等离子体（13.56 MHz）、RIE/溅射/CVD/ALD。
5. **自动化控制**——4–20 mA 变送器、PID、PLC 梯形图、DCS 组态；红石的正式继承者。
6. **良率工程**——颗粒/金属污染/缺陷密度；同样工艺，良率决定成本。

## 2. 开局与世界生成

### 2.1 出生点保障

阶段 8 的电子材料区保证：

- **高纯石英砂**（低铁）、**萤石**（HF）、**石墨**（热场/电极）、**硼/磷/砷矿**（掺杂源）；
- **空分产品**（N₂/Ar/稀有气体：氖/氪/氙，用于准分子激光）；
- 光刻胶原料（苯酚/萘/丙烯酸酯）、双氧水、氨、盐酸（电子级）；
- 洁净水源、稳定电力（阶段 5 电网）。

### 2.2 原版内容调整（本阶段生效范围）

- 电子级试剂为独立物品（ppb 级金属杂质；与工业级同物质不同质量档）；
- 洁净室/UPW 系统/真空系统为可建造结构；
- 控制全面转向仪表与 PLC/DCS（红石保持移除）；
- 芯片/传感器/激光为独立物品，用于自动化与阶段 9 的仪器。

### 2.3 气候与季节

- 洁净室空调/新风能耗大；湿度影响光刻胶与静电；
- UPW 系统连续运行，停机会导致水质恢复慢；
- 电力质量（电压波动）影响光刻对准与离子注入。

## 3. 核心机制

### 3.1 超纯水与洁净室

- UPW：砂滤 → 活性炭 → 软化 → RO → EDI → UV（185/254 nm）→ 抛光混床 → 0.1 µm 过滤 → 18.2 MΩ·cm（25 °C）、TOC <1 ppb；
- 洁净室：ISO 14644-1 分级（ISO 1–5），HEPA/ULPA、正压、风淋、防静电；颗粒计数在线；
- 电子级试剂：HF/H₂O₂/HCl/NH₃ 等经亚沸蒸馏/离子交换/膜过滤，金属杂质 ppb–ppt。

### 3.2 硅的提纯与单晶

- 冶金硅：石英砂 + 焦炭，电弧炉 1900 °C → 98–99% Si；
- 西门子法：Si + 3HCl → SiHCl₃（~300 °C，Cu 催化）→ 精馏 → H₂ 还原沉积（1100–1150 °C 硅棒）→ 多晶硅 9N–11N；副产 SiCl₄ 循环（改良西门子法闭环）；
- CZ 直拉：多晶硅 + 掺杂剂（B/P/As）→ 石英坩埚熔融（1420 °C）→ 籽晶引晶 → 缩颈/放肩/等径 → 提拉 1–2 mm/min、旋转 → 单晶锭；氧含量/位错/热场控制；
- 切片（金刚线）→ 研磨 → CMP 抛光 → 晶圆（200/300 mm）。

### 3.3 光刻（本阶段 Boss 的核心）

- 光刻胶：g/i 线（酚醛 + 重氮萘醌 DNQ）→ KrF 248 nm（PHS + PAG 化学放大）→ ArF 193 nm（丙烯酸酯类）；
- 流程：清洗（RCA：SC-1 NH₄OH/H₂O₂/H₂O 75–80 °C、SC-2 HCl/H₂O₂/H₂O、HF 漂洗）→ 热氧化（900–1100 °C，数十至数百 nm SiO₂）→ 涂胶/前烘 → 曝光（掩模/步进）→ 后烘 → 显影（TMAH 2.38%）→ 刻蚀 → 去胶；
- 分辨率：g 线 ~0.35 µm、i 线 ~0.25 µm、KrF ~0.13 µm、ArF ~0.045 µm、EUV 13.5 nm 更小；
- 对准/套刻误差、曝光剂量、焦距是良率关键。

### 3.4 刻蚀与薄膜

- 湿法刻蚀（HF/HNO₃/磷酸）各向同性；干法 RIE（CF₄/SF₆/Cl₂ 等离子体，13.56 MHz）各向异性；
- 薄膜：热氧化（SiO₂）、LPCVD（多晶硅/氮化硅）、PECVD（250–400 °C）、溅射（Al/Cu/Ti/W）、蒸发、ALD（原子层）；
- 互连：铝 → 铜大马士革（电镀 + CMP）。

### 3.5 掺杂

- 扩散：热扩散炉（900–1100 °C）+ 掺杂源（POCl₃/BN）；
- 离子注入：离子源（BF₃/PH₃/AsH₃）→ 加速（10–200 keV）→ 磁分析 → 扫描 → 退火（RTP 1000–1100 °C，秒级）；
- 掺杂浓度/结深决定器件参数。

### 3.6 真空与等离子体

- 真空：干泵/罗茨泵/涡轮分子泵（<10⁻⁵ Pa）、氦检漏；
- 等离子体：RF 电源 + 匹配网络 + MFC 气体流量控制；RIE/溅射/PECVD；
- 真空腔体材料（不锈钢/铝）、密封（O 圈/金属密封）、清洁。

### 3.7 自动化（红石的正式替代）

- 传感器：热电偶/热电阻、压力/差压、流量（孔板/质量流量计）、液位、pH/电导、气体分析；
- 变送器 4–20 mA → PLC（梯形图）→ 执行器（调节阀/变频器）；
- DCS：操作站 + 组态 + PID 整定（阶跃响应）；联锁/报警/趋势；
- 应用：合成氨装置 DCS 改造（阶段 4 的循环回路自动化）、精馏塔温控、反应釜温压联锁。

### 3.8 良率工程

- 颗粒/金属污染/缺陷密度；每道工序的良率相乘；
- 统计过程控制（SPC）；设备维护/校准；洁净服/行为规范。

## 5. 工艺链详细设计

### 5.1 UPW 与电子级试剂（6–8 h）

原水 → 多级处理 → 18.2 MΩ·cm；电子级酸/碱/双氧水（亚沸蒸馏 + 离子交换 + 膜过滤）；金属杂质 ppb 级验证（ICP-MS? 本阶段用在线分析/标准曲线）。

### 5.2 多晶硅（西门子法）（8–10 h）

冶金硅（电弧炉）→ 破碎/氯化（HCl，300 °C，Cu 催化）→ SiHCl₃ 精馏（多级）→ 还原炉（1100–1150 °C 硅棒，H₂ 还原）→ 多晶硅 9N–11N；SiCl₄ 回收转化（闭环）；能耗/腐蚀/安全。

### 5.3 CZ 单晶与晶圆（8–10 h）

多晶硅 + 掺杂 → 石英坩埚熔融（1420 °C）→ 籽晶引晶 → 缩颈/放肩/等径（提拉 1–2 mm/min、旋转）→ 单晶锭 → 切片（金刚线）→ 研磨 → CMP → 晶圆；检测：电阻率/少子寿命/位错/氧含量。

### 5.4 光刻（12–16 h，阶段 Boss 核心）

RCA 清洗 → 热氧化 → 涂胶 → 前烘 → 曝光（掩模/步进）→ 后烘 → 显影（TMAH）→ 刻蚀 → 去胶；多层套刻对准；分辨率/焦深/剂量窗口；缺陷检查（显微镜）。

### 5.5 刻蚀与薄膜（8–10 h）

RIE（CF₄/SF₆/Cl₂，13.56 MHz）各向异性刻蚀；LPCVD/PECVD/溅射/蒸发/ALD；台阶覆盖/均匀性/应力；铜互连（电镀 + CMP）。

### 5.6 掺杂（6–8 h）

扩散（POCl₃/BN，900–1100 °C）→ 结深/方块电阻；离子注入（10–200 keV，剂量 10¹¹–10¹⁶ cm⁻²）→ RTP 退火；掺杂分布（四探针/霍尔）。

### 5.7 真空与等离子体（6–8 h）

真空系统（干泵/涡轮泵/检漏）；RF 等离子体（匹配网络/MFC）；RIE/溅射/PECVD 调试；腔体清洁/颗粒控制。

### 5.8 PLC/DCS 自动化（8–10 h）

传感器 → 变送器 → PLC 梯形图 → 调节阀；PID 整定（阶跃响应/稳定性）；DCS 组态（合成氨装置改造）；联锁/报警/趋势；黑灯工厂成就。

### 5.9 集成电路全流程（10–14 h）

晶圆 → 氧化 → 光刻（多层）→ 刻蚀 → 注入 → 薄膜 → CMP → 互连 → 测试；成品率/失效分析（显微镜/探针台）。

### 5.10 激光与光学（4–6 h）

红宝石激光（694.3 nm，1960）→ CO₂ 激光（10.6 µm）→ 准分子（KrF 248/ArF 193）→ Nd:YAG（1064 nm，掺钕钇铝石榴石）；激光用于光刻光源/切割/测距/光谱。

## 7. 里程碑与阶段出口

**九项必需（研究手册逐条记录）：**

1. **UPW**：18.2 MΩ·cm + TOC 达标；
2. **电子级试剂**：HF/H₂O₂ 金属杂质 ppb 级验证；
3. **多晶硅**：西门子法 9N–11N；
4. **CZ 单晶**：无位错/电阻率达标；
5. **晶圆**：切片/CMP 平整度达标；
6. **光刻**：单层图形转移成功（线宽/套刻）；
7. **刻蚀/薄膜/掺杂**：各一道工序达标；
8. **集成电路**：完整流程出第一块芯片（**阶段 Boss**）；
9. **PLC/DCS**：合成氨装置自动化改造 + 黑灯工厂成就。

**出口任务「终局的召唤」**：用 DCS 全自动产线连续运行 24 h；电子级试剂 + 自制仪器完成一次 ppb 级验证——研究手册解锁阶段 9："最后一关，是分子与晶体。"

## 10. 实现要点（技术）

- **超纯**：多级处理链 + 在线电阻率/TOC；水质影响良率；
- **西门子法**：氯化/精馏/还原三段；纯度（ppb）与能耗；
- **CZ**：温度场 + 提拉速度 + 旋转 → 缺陷/氧含量/电阻率；
- **光刻**：涂胶厚度/曝光剂量/焦距/对准 → 线宽/良率；掩模层数；
- **刻蚀/薄膜**：各向异性/选择比/均匀性；
- **掺杂**：浓度/结深（四探针/霍尔测量）；
- **自动化**：传感器→PLC→执行器；PID 整定；DCS 组态；
- **良率**：粒子/缺陷模型；每道工序良率相乘；
- **数据驱动**：工艺参数、设备规格、良率模型 JSON 化。
