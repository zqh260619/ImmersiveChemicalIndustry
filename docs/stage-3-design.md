# 阶段 3 详细设计：化学革命——酸·碱·焦化（50–80 h）

> 总纲：[game-progression.md](game-progression.md) 阶段 3

## 1. 设计定位：本阶段要教的六个"终身技能"

1. **干馏与焦化**——煤在隔绝空气下加热，得到焦炭、煤气、煤焦油、氨水；"燃烧"与"干馏"是两件完全不同的事。
2. **酸化学**——SO₂ 的催化氧化（NOx 传递氧）、挥发性酸的蒸馏、浓度与共沸（硫酸 98%、盐酸 20.2%、硝酸 68.4%）。
3. **碱与联产**——勒布朗法"制碱必产盐酸"，索尔维法"氨循环 + CO₂ 循环"；联产是化工经济的第一课。
4. **玻璃仪器与测量**——硼硅玻璃吹制（铁吹管来自阶段 2）；温度计、气压计、天平让"量化"成为可能。
5. **分析化学**——石蕊、滴定、基准纯碱；第一次用"刻度"而不是"颜色"判断物质。
6. **气体操作与安全**——Cl₂、SO₂、HCl、CO 的处理；吸收塔、通风、湿布/防毒面具。

## 2. 开局与世界生成

### 2.1 出生点保障

阶段 3 的工业区保证：

- **煤矿**：露头 + 浅层煤层（烟煤为主）；
- **铅锌矿**：方铅矿（PbS，含银）、闪锌矿（ZnS）——铅室、银、锌；
- **硼砂**：盐湖/干涸湖盆蒸发岩（硼硅玻璃）；
- **软锰矿**（MnO₂，制氯）、**辰砂**（HgS，制汞）；
- 硝石（阶段 2 硝床）、石灰石、岩盐、黏土、石英砂。

### 2.2 原版内容调整（本阶段生效范围）

- 煤只能用于燃料与干馏，不能直接炼铁（焦炭才行）；
- 原版火把/灯笼保留，但煤气灯是新的照明体系；
- 硫酸/盐酸/硝酸为流体（混合物物质，浓度档独立）；
- 玻璃仪器为独立物品（烧瓶/曲颈甑/冷凝管/分液漏斗/滴定管），不是原版玻璃的简单合成；
- 铅、汞、氯气有毒性机制（见 §8）。

### 2.3 气候与季节

- 冬季煤耗上升；焦炉需连续运行，熄灭即损失；
- 硼砂开采受盐湖季节水位影响；
- 玻璃吹制/退火对温差敏感（冬季良品率下降）。

## 3. 核心机制

### 3.1 干馏与焦化

| 产物 | 产率（质量） | 用途 |
|---|---|---|
| 焦炭 | ~70% | 高炉燃料、还原剂 |
| 煤气 | ~15% | 照明、加热（H₂/CH₄/CO 混合） |
| 煤焦油 | 3–5% | 阶段 4 分馏（苯/甲苯/萘/酚/蒽） |
| 氨水 | 少量 | 氨源（托伦试剂、索尔维循环） |

- 焦炉 900–1100 °C、隔绝空气、缓慢干馏（数小时）；
- 副产回收焦炉（砖砌、密封、集气管、冷凝器）vs 蜂巢焦炉（只出焦炭）——前者是阶段 4 有机化学的入口；
- 焦炭质量：固定碳 ≥80%、灰分 ≤12%、硫 ≤1%；"焦炭成熟度"用挥发分/外观判定。

### 3.2 酸化学

- **硫酸**：
  - 绿矾干馏（FeSO₄·7H₂O → FeSO₄ → Fe₂O₃ + SO₂ + SO₃，约 500–700 °C）→ 冷凝得"矾油"（发烟硫酸，实验室少量）；
  - 铅室法：SO₂（黄铁矿焙烧/硫磺燃烧，300–500 °C 进气）+ NOx 循环（NO + NO₂ → N₂O₃；SO₂ + N₂O₃ + H₂O → H₂SO₄ + 2NO）+ 水蒸气 → 65–78% 稀硫酸；铅室因稀酸腐蚀性强必须用铅；
  - 浓缩：玻璃/铂蒸馏釜加热脱水 → 90%+；98% 与发烟硫酸留到阶段 4 接触法。
- **盐酸**：NaCl + H₂SO₄ → NaHSO₄ + HCl↑（约 150 °C）；NaHSO₄ + NaCl → Na₂SO₄ + HCl↑（500–600 °C）；HCl 气体经水吸收 → 31% 工业盐酸；恒沸点 20.2%。
- **硝酸**：KNO₃ + H₂SO₄ → KHSO₄ + HNO₃，蒸馏收集（68.4% 共沸）；浓硫酸脱水可得发烟硝酸；王水 = 3 体积盐酸 : 1 体积硝酸。
- **酸的安全**：SO₂/NOx/Cl₂ 有毒；浓硫酸稀释必须"酸入水"；硝酸见光分解。

### 3.3 碱与联产

**勒布朗法（1791）**：

```
2NaCl + H₂SO₄ → Na₂SO₄ + 2HCl↑          （盐酸副产）
Na₂SO₄ + 2C → Na₂S + 2CO₂↑
Na₂S + CaCO₃ → Na₂CO₃ + CaS
```

- 配比（质量）芒硝 : 石灰石 : 煤 ≈ 100 : 100 : 35.5，反射炉 950–1000 °C 熔融成"黑灰"；
- 浸取 → 蒸发结晶 → 纯碱（80–90% 粗品）；副产 HCl 回收成盐酸/氯气；废渣（CaS）堆存污染——真实历史教训。

**索尔维法（1861，本阶段 Boss）**：

```
2NH₃ + CO₂ + H₂O → (NH₄)₂CO₃
(NH₄)₂CO₃ + CO₂ + H₂O → 2NH₄HCO₃
2NH₄HCO₃ + 2NaCl → 2NaHCO₃↓ + 2NH₄Cl
2NaHCO₃ → Na₂CO₃ + CO₂↑ + H₂O（160–200 °C 煅烧）
```

- 氨盐水冷却到 35 °C 以下，通入石灰窑气（CO₂ ~30%），NaHCO₃ 结晶析出；
- 过滤 → 煅烧 → 纯碱（98%+）；母液加石灰乳蒸氨：2NH₄Cl + Ca(OH)₂ → CaCl₂ + 2NH₃↑ + 2H₂O，氨循环；
- CO₂ 来自石灰窑（CaCO₃ → CaO + CO₂），石灰又用于蒸氨——**钙循环 + 氨循环 + CO₂ 循环**三重耦合，是阶段 3 的工程考试。

### 3.4 玻璃仪器与测量

- 硼硅玻璃（Pyrex 类）：SiO₂ 80.6%、B₂O₃ 13%、Na₂O 4%、Al₂O₃ 2.3%；熔制 ~1600 °C（焦炭 + 强鼓风），工作温度 ~1250 °C，退火 ~560 °C；
- 铁吹管（阶段 2 的钢/铁管）→ 吹制烧瓶、曲颈甑、试管；灯工（小火焰）加工；
- 仪器清单：烧瓶（圆底/平底）、曲颈甑、李比希冷凝管、分液漏斗、滴定管、量筒、表面皿；
- 温度计：辰砂焙烧提汞（HgS + O₂ → Hg + SO₂，500–700 °C）→ 水银温度计（−38.8 ~ 356.7 °C）；冰水 0 °C / 沸水 100 °C 两点校准；
- 气压计：托里拆利管，760 mmHg；
- 天平：等臂天平 + 砝码组（0.1 g 精度起步）。

### 3.5 分析化学

- 指示剂：石蕊（地衣浸提）、紫甘蓝汁；酚酞/甲基橙留到阶段 7；
- 滴定：基准纯碱标定盐酸（Na₂CO₃ + 2HCl → 2NaCl + CO₂ + H₂O）；滴定管 + 指示剂 → 酸/碱浓度定量；
- 银镜反应：方铅矿提银（吹灰法）→ AgNO₃ → 托伦试剂（Ag(NH₃)₂OH，氨来自焦炉氨水）→ 醛基检测。

### 3.6 气体操作与安全

- 吸收塔（填料塔/喷淋塔）吸收 HCl/SO₂/Cl₂；
- Cl₂：MnO₂ + 4HCl（浓）→ MnCl₂ + Cl₂↑ + 2H₂O（加热）；漂白粉：Cl₂ + Ca(OH)₂ → Ca(OCl)Cl；
- 通风橱雏形（负压 + 排风），湿布/碱液吸收应急。

## 5. 工艺链详细设计

### 5.1 采煤与焦化（4–6 h）

煤矿露头 → 竖井/斜井（阶段 2 技术）→ 采煤（瓦斯/粉尘安全）→ 焦炉装煤 → 干馏 900–1100 °C 数小时 → 出焦（熄焦：水/干熄）→ 焦炭；副产煤气（洗涤/脱硫? 本阶段简单水洗）、焦油（静置分层）、氨水（冷凝液）。

### 5.2 硫酸（5–8 h）

绿矾干馏（少量矾油，验证路线）→ 建铅室（铅板铆接，室内衬耐酸）→ 黄铁矿焙烧炉（300–500 °C 进气）+ 硝石/NOx 补充 → 铅室吸收 → 65–78% 硫酸 → 玻璃蒸馏釜浓缩（90%+）。铅室酸含氮氧化物 → 脱硝（加热/吹气）。

### 5.3 盐酸（3–5 h）

NaCl + H₂SO₄ 反应釜（150 °C 首段；500–600 °C 二段）→ HCl 气体 → 吸收塔（水喷淋）→ 31% 盐酸；尾气碱洗。副产芒硝（Na₂SO₄）留给勒布朗法。

### 5.4 硝酸与王水（3–4 h）

硝石 + 浓硫酸在曲颈甑中蒸馏 → 硝酸冷凝（68%）；浓硫酸脱水 → 发烟硝酸；王水现配现用（3:1），溶解金/铂（阶段 4 贵金属回收前置）。

### 5.5 勒布朗制碱（6–8 h，可选路线）

芒硝 + 煤 + 石灰石（100:100:35.5）→ 反射炉 950–1000 °C → 黑灰 → 浸取（水）→ 过滤 → 蒸发结晶 → 粗纯碱；HCl 副产回收；废渣（CaS）处理（环保教训）。

### 5.6 索尔维制碱（8–12 h，本阶段 Boss）

盐水精制（除 Ca/Mg）→ 吸氨（氨水/焦炉氨）→ 冷却 → 碳酸化塔（CO₂ from 石灰窑，35 °C 以下）→ NaHCO₃ 结晶 → 过滤 → 煅烧（160–200 °C）→ 纯碱；母液 + 石灰乳 → 蒸氨塔 → 氨循环；CO₂ 循环。考核：纯碱 98%+、氨耗、盐利用率。

### 5.7 玻璃仪器（5–8 h）

硼砂 + 石英砂 + 少量石灰石/长石 → 硼硅玻璃配合料 → 1600 °C 熔制（焦炭 + 强鼓风 + 坩埚）→ 铁吹管取料 → 吹制/灯工 → 退火 560 °C → 仪器；良品率受气泡/内应力影响。

### 5.8 温度计/气压计/天平（3–5 h）

辰砂焙烧 → 汞（冷凝收集，**剧毒**）→ 玻璃管 + 汞球 → 刻度（冰水/沸水两点）→ 温度计；托里拆利管 + 汞槽 → 气压计；等臂天平 + 砝码校准（阶段 7 才有更高精度）。

### 5.9 分析化学（3–5 h）

石蕊试纸（地衣浸提）→ 酸碱滴定：基准纯碱标定盐酸 → 滴定未知酸/碱 → 计算浓度；研究手册记录"第一次定量分析"，解锁后续所有浓度判定。

### 5.10 氯气与漂白粉（3–5 h）

软锰矿 + 浓盐酸加热 → Cl₂ → 石灰乳吸收 → 漂白粉；Cl₂ 用于漂白与消毒（纺织升级）；安全：通风/碱液吸收/湿布。

### 5.11 银与托伦试剂（2–3 h）

方铅矿吹灰法提银（铅氧化被骨灰吸收，银留下）→ 硝酸溶解 → AgNO₃ → 加氨水至沉淀溶解 → 托伦试剂 → 醛基检测（银镜）；这是阶段 7 糖类/醛检测的前置。

### 5.12 煤气与照明（2–3 h）

焦炉煤气 → 水洗/脱焦油 → 管道（铸铁管/铅管）→ 煤气灯；煤气泄漏（CO/H₂/CH₄）检测与通风；夜间照明让工厂可 24 h 运行。

## 7. 里程碑与阶段出口

**七项必需（研究手册逐条记录）：**

1. **焦炭 + 煤气**：副产回收焦炉连续运行，焦炭质量达标；
2. **铅室硫酸**：65%+，滴定标定浓度；
3. **盐酸/硝酸**：浓度标定（31%/68%）；
4. **纯碱**：勒布朗或索尔维任一路线，98%+（索尔维为推荐路线）；
5. **硼硅玻璃仪器**：烧瓶 + 冷凝管 + 滴定管一套，退火无炸裂；
6. **温度计/天平/滴定**：完成一次酸碱滴定并算出浓度；
7. **漂白粉 + 煤气照明**：各一项应用落地。

**出口任务「蒸汽的召唤」**：用焦炭高炉炼出生铁，铸出一只"气缸毛坯"；用密封铁罐加热少量水，观察到蒸汽压力顶开安全阀——研究手册解锁阶段 4："蒸汽可以推动活塞。"

| 汞中毒 | 辰砂焙烧、温度计破损 | 慢性神经损伤；通风/硫粉处理 |
| Cl₂/SO₂ 中毒 | 制氯、焙烧、酸雾 | 呼吸道损伤；吸收塔/湿布 |
| 酸灼伤 | 浓硫酸稀释、硝酸蒸馏 | 重度烧伤；"酸入水"规则 |
| 铅室腐蚀/漏气 | 稀酸 + NOx | 酸雾泄漏、产量下降 |
| 索尔维氨耗高 | 蒸氨不完全 | 成本爆炸、氨味污染 |
| 玻璃炸裂 | 退火不当/局部过热 | 仪器报废、割伤 |
| 煤气爆炸 | 泄漏 + 明火 | 燃爆；通风/检测 |
| 焦炉熄火 | 连续运行中断 | 焦炭报废、焦油/煤气损失 |

## 10. 实现要点（技术）

- **焦炉**多方块：装煤/加热/出焦/副产收集；温度曲线影响焦炭质量与焦油产率；
- **铅室法**：SO₂ 进气 + NOx 循环 + 水蒸气 + 酸雾凝结；转化率随温度/配比/停留时间变化；
- **索尔维**：氨盐水碳酸化（温度、CO₂ 分压、盐浓度）→ 结晶；蒸氨塔（石灰乳、蒸汽）→ 氨回收率；
- **玻璃仪器**：吹制小游戏/配方：玻璃液 + 铁吹管 → 仪器（良品率受气泡/退火影响）；
- **测量仪器**：温度计/气压计/天平为物品，读数用于配方判定（如"必须 65%+ 硫酸"）；
- **滴定**：GUI 操作（滴定管读数 + 指示剂变色），结果写入手册并解锁浓度判定；
- **危险**：铅/汞/氯气/酸雾的暴露值（时间累积）与 PPE；
- **数据驱动**：酸浓度档、碱路线、玻璃配方、仪器规格 JSON 化。
