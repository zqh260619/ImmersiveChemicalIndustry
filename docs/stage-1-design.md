## 1. 设计定位：本阶段要教的六个"终身技能"

1. **鼓风与温度上限**——风箱把窑从 1000 °C 推到 1200 °C（熔铜）再到 1450 °C（熔玻璃）；温度阶梯从此由"鼓风"而不是"柴火"决定。
2. **选矿与品位**——破碎、筛分、水洗重选（砂锡）、手选；品位决定炉料配比与渣量。
3. **合金配比**——Cu:Sn ≈ 88:12（质量）不是拍脑袋：锡含量决定硬度与脆性，成分公差是质量属性（与物质系统 §2.6 对接）。
4. **玻璃与观察**——透明容器让"看见反应"成为可能；透镜把眼睛延伸到微米级，微生物由此登场。
5. **发酵**——糖化（酶）、酒精发酵（酵母）、醋酸发酵（醋酸菌）三种生物过程，首次遇到"温度、氧气、杂菌"三参数。
6. **蒸馏**——沸点差分离的第一课；酒精度上限与共沸点（95.6%）是阶段 3 分馏塔、阶段 6 精馏塔的种子。

## 2. 开局与世界生成

### 2.1 出生点保障

阶段 1 的出生点（或阶段 0 出口任务指向的区域）半径 800 格内保证：

- **铜矿露头**：孔雀石（翠绿）、蓝铜矿（深蓝）氧化带，伴生赤铜矿；
- **锡石砂矿**：河滩/滨海的黑色重砂（密度 6.8–7.0 g/cm³，淘洗可见）；
- **石英砂**：河滩/风化的花岗岩；
- **石灰石**（阶段 0 已用）、**盐**（阶段 0 已用）；
- 森林（燃料与树皮单宁）、黏土（坩埚/陶范）。

### 2.2 原版内容调整（本阶段生效范围）

- 禁用原版熔炉烧玻璃、烧铜/锡/青铜的配方；金属只能由本阶段炉窑产出；
- 工具/武器 tier：燧石 < 铜 < 青铜；铜工具软（易卷刃），青铜才耐用；
- 原版玻璃/玻璃板只能由本阶段熔窑产出（熔制 + 退火）；窗户与容器从此可造；
- 原版"桶装水"保留，但酒/醋/烈酒是独立流体（混合物物质，见物质系统 §2.4）；
- 怪物与生存规则延续阶段 0（无亡灵类，野生动物 + 环境）。

### 2.3 气候与季节

- 雨季影响：窑炉需遮雨棚；玻璃退火怕急冷；发酵温度随季节波动（冬季需保温，夏季需降温）；
- 森林砍伐压力：熔铜/熔玻璃燃料消耗是阶段 0 的数倍，逼玩家开始种树/烧木炭。

## 3. 核心机制

### 3.1 鼓风与温度

| 装置 | 可达温度 | 材料 | 用途 |
|---|---|---|---|
| 皮囊风箱 | 1100–1200 °C | 皮革 + 木框 + 陶风嘴 | 熔铜、炼锡 |
| 脚踏风箱 | 1200–1300 °C | 木板 + 皮革活塞 + 陶风嘴 | 青铜熔炼、竖炉 |
| 双风箱/风嘴对吹 | 1350–1450 °C | 两套风箱 + 耐火陶/石炉 | 玻璃熔制 |

- 火色判温延伸到 **亮黄（1200 °C）、黄白（1400 °C）**；超过 1450 °C 本阶段材料无法承受（炉衬软化）；
- 风量不足 → 炉温上不去 + 还原不完全（渣中带铜）；风量过大 → 燃料浪费、炉衬侵蚀、铜氧化损失。

### 3.2 选矿三法

| 方法 | 原理 | 适用 |
|---|---|---|
| 手选 | 颜色/密度肉眼分选 | 孔雀石、蓝铜矿 |
| 水洗重选 | 密度差（锡石 6.8–7.0 vs 砂 2.65） | 砂锡、河滩重砂 |
| 破碎筛分 | 粒度分级，富集有用矿物 | 脉石矿、精矿准备 |

品位（assay）是质量属性：原矿 3–8% Cu、精矿 25–35% Cu；炉料按品位配渣（SiO₂/FeO 比例），渣过黏 → 铜损失。

### 3.3 合金与配比

- 青铜 = Cu 88% + Sn 12%（质量），成分公差 ±3%；
- 硬度随锡含量上升，超过 ~15% 变脆（参考高锡青铜研究：硬度到 ~22% Sn 附近见顶，但脆性显著增加）；
- 判定手段：**刻划/弯曲试验 + 断口颜色**；后期（阶段 3）才有硬度计与金相；
- 浇铸温度 1050–1150 °C（高于液相线 ~1000 °C），陶范需预热，否则冷隔/气孔。

### 3.4 玻璃：没有铁，就没有吹制

- 历史事实：玻璃吹制需要 **铁制吹管**（耐 1200–1400 °C），本阶段无铁 → 只能**砂芯法/模压/铸造**：
  - 砂芯法：用砂+黏土做芯，玻璃液缠绕/包裹，冷却后掏芯 → 小瓶、珠；
  - 模压：两瓣陶模压出珠、饰片、简单器皿；
  - 铸造+研磨：浇成圆饼，磨成透镜（见 5.7）。
- 配方（质量份）：石英砂 70 + 石灰石 12 + 草木灰钾碱 18；熔融 1350–1450 °C；
- **澄清**：高温保持 2–4 h，让气泡上浮（黏度随温度下降）；气泡残留 = 废品（散射/强度差）；
- **退火**：500–550 °C 保温后缓慢冷却 4–8 h，否则内应力炸裂；
- 颜色：铁杂质使玻璃发绿（真实！），可通过选纯石英砂/加锰? 本阶段无锰提纯 → 绿玻璃是常态，无色玻璃是阶段 3+ 的目标。

### 3.5 透镜与显微镜（观察的延伸）

- 磨制流程：粗磨（60–120 目砂）→ 细磨（240–600 目）→ 抛光（氧化铁红/锡盘）；
- 单透镜放大 30–300×（Leeuwenhoek 式单透镜可达 200×+）；焦距 20–50 mm；
- 显微镜组装：镜筒（木/铜）、载物台、反光镜；调焦靠滑筒；
- **观察对象**：酵母（3–4 µm，150×+ 可见）、纤维、淀粉颗粒（阶段 7 的偏光十字伏笔）；
- 微生物概念解锁：研究手册记"酒/醋/面团里有活的微小生物"，引出灭菌与接种。

### 3.6 发酵与蒸馏

- **麦芽制备**：大麦浸泡 → 发芽 3–5 天（淀粉酶活化）→ 烘干（60–70 °C 终止发芽）；
- **糖化**：麦芽粉 + 水 65 °C 保温 1–2 h（淀粉 → 麦芽糖/葡萄糖）；
- **酒精发酵**：冷却至 20–25 °C，接种酵母，3–7 天 → 5–8% vol（酵母耐受上限 ~14–16%，实际麦酒 5–8%）；
- **醋酸发酵**：酒 + 醋酸菌 "母"（30 °C、供氧、2–4 周）→ 5–8% 醋酸；
- **蒸馏**：铜蒸馏器（铜熔点 1085 °C，远高于蒸馏温度）；酒 5–8% → 一次蒸馏 40–60% → 二次 70–80%；乙醇-水共沸 95.6%（78.2 °C），"为什么蒸不出 100%"是阶段 3 分馏/阶段 6 精馏的伏笔。

## 5. 工艺链详细设计

### 5.1 鼓风装置（0.5–1 h）

皮囊风箱：皮革（阶段 0 生皮 → 阶段 1 鞣制）缝制 + 木框 + 陶风嘴；脚踏风箱需要木板与皮革活塞——**这是"用生物材料造机器"的第一课**。风嘴插入炉口 10–20 cm，避免烧融。

### 5.2 找矿与选矿（1–2 h）

露头识别（颜色）→ 破碎（石锤）→ 手选 → 淘洗（砂锡）→ 精矿；品位用"称重 + 目测"估算（阶段 3 才有滴定/分析）。砂锡淘洗在河滩水流中进行（真实的重选）。

### 5.3 炼铜（2–3 h）

- **氧化矿**（孔雀石/蓝铜矿）：破碎 → 与木炭分层装入坩埚/竖炉 → 鼓风 1100–1200 °C；
  - 分解：Cu₂CO₃(OH)₂ → 2CuO + CO₂↑ + H₂O↑（300–400 °C）；
  - 还原：CuO + C → Cu + CO↑（700–900 °C 起）；
  - 熔融：1085 °C，铜液沉底，渣浮面；
- **硫化矿**（黄铜矿，本阶段只能"勉强处理"）：焙烧 500–700 °C 脱硫（2CuFeS₂ + O₂ → Cu₂S + 2FeS + SO₂↑，**SO₂ 呛鼻、有毒**）→ 加木炭/石英砂还原熔炼 → 粗铜（收率低、含铁硫杂质高）——正式冰铜吹炼留到阶段 3；
- 产物：粗铜锭（95–98% Cu），需重熔精炼；渣（硅酸铁）可作建筑材料。

### 5.4 炼锡（1–2 h）

砂锡淘洗 → 锡石精矿（SnO₂ 60–70%）→ 与木炭同装坩埚，鼓风 1200 °C：SnO₂ + 2C → Sn + 2CO↑；锡熔点仅 232 °C，出炉后极易铸成锭/粒。锡稀缺 → 贸易/远行，是阶段 1 的"地理压力"。

### 5.5 青铜合金与铸造（2–3 h）

坩埚先熔铜（1100–1150 °C）→ 加锡（先预热，防爆溅）→ 搅拌 → 撇渣 → 浇入预热陶范；配比 88:12（质量），公差 ±3%；硬度用刻划/弯曲试验判定；成分不合格 → 重熔补料。工具成品率与配比、浇铸温度、范温直接相关。

### 5.6 玻璃熔制（3–5 h，本阶段 Boss）

配料（石英砂 70 : 石灰石 12 : 钾碱 18）→ 混合 → 熔窑 1350–1450 °C（双风箱）→ 澄清 2–4 h → 取料：
- 砂芯法做瓶/珠；模压做饰片；浇铸做饼（透镜坯）；
- 退火 500–550 °C 缓冷 4–8 h；
- 判定：气泡数量、颜色（绿=铁杂质）、内应力（偏振光? 本阶段无偏光片 → 用"敲击声/冷热骤变测试"）。

### 5.7 透镜与显微镜（2–3 h）

铸造玻璃饼 → 粗磨成型（砂盘）→ 细磨 → 抛光 → 检验焦距（太阳聚焦/成像）→ 装镜筒；单透镜 150×+ 即可观察酵母。研究手册记录"微生物"条目，解锁灭菌/接种概念。

### 5.8 发酵：酒与醋（2–3 h）

麦芽 → 糖化 → 过滤 → 煮沸（灭菌）→ 冷却 → 接种 → 主发酵（20–25 °C，3–7 天）→ 酒；酒 + 醋母（30 °C、供氧）→ 醋。杂菌污染（乳酸/野生酵母）→ 酸败/异味，整罐报废；灭菌（煮沸）与接种（酒母/醋母）是阶段 7 发酵工程的前置。

### 5.9 蒸馏（1–2 h）

铜蒸馏器（铜板铆接/锡焊）+ 冷凝管（铜管盘绕）+ 接收瓶；酒 5–8% → 一次 40–60% → 二次 70–80%；温度控制靠火色（78.3 °C 乙醇沸点附近），"酒头/酒心/酒尾"的切分是经验。共沸 95.6% 检测 → 阶段 3 分馏伏笔。

### 5.10 肥皂与鞣革（1–2 h）

- 肥皂：油脂（动物脂/植物油）+ 碱液（石灰苛化钾碱：K₂CO₃ + Ca(OH)₂ → 2KOH + CaCO₃↓）→ 90–100 °C 皂化 2–3 h → 盐析（NaCl 10–15%）→ 上层皂基 → 成型；副产甘油留在废液（阶段 4 回收）；
- 鞣革：生皮 → 石灰水浸 3–7 天（脱毛/膨胀）→ 刮肉 → 单宁液（树皮浸提）逐级增浓鞣制 2–4 周（游戏压缩 5–10 天）→ 晾干；皮革用于风箱、护具、传动带。

## 7. 里程碑与阶段出口

**七项必需（研究手册逐条记录）：**

1. **鼓风炉**：稳定达到 1200 °C（火色亮黄），熔出第一炉铜；
2. **锡锭**：砂锡淘洗 → 还原 → 铸锭；
3. **青铜锭**：Cu:Sn = 88:12 ± 3%，刻划/弯曲试验合格；
4. **透明玻璃器**：气泡 ≤ 标准、退火无炸裂，至少一件砂芯法瓶/珠；
5. **透镜 + 显微镜**：150× 以上，观察到酵母并记录；
6. **酒与醋**：各一坛合格（酒 5–8%、醋 5–8%）；
7. **肥皂**：皂化 + 盐析成功。

**出口任务「铁的召唤」**：用磁石在河滩/山麓找到黑色磁性砂或红色铁矿露头，采集 1 块磁铁矿/赤铁矿；研究手册解锁阶段 2 预览："铁的熔点更高、需要更强的鼓风与更高的炉身——块炼铁。"同时提示：青铜工具无法有效加工铁矿石（硬度不足）。

| 事故 | 触发 | 后果 |
|---|---|---|
| SO₂ 中毒 | 焙烧硫化矿、熔炼含硫矿 | 咳嗽/窒息 debuff；需上风口、湿布/防毒面具（阶段 3+） |
| 铜/锡液烫伤 | 浇铸、坩埚倾覆 | 高伤害；需皮革围裙/护腿 |
| 玻璃炸裂 | 退火不当、冷热骤变 | 报废；碎片割伤 |
| 发酵染菌 | 灭菌不彻底、敞口 | 整罐酸败；需煮沸+接种+水封 |
| 蒸馏火灾 | 酒精蒸气遇明火 | 燃爆；需冷凝完全、远离火源 |
| 锡稀缺 | 砂矿有限 | 迫使远行/贸易；配比不足 → 青铜性能不达标 |
| 燃料危机 | 森林砍伐 | 熔窑燃料成本上升；逼向木炭/种树 |

## 10. 实现要点（技术）

- **风箱与炉温**：风箱作为多方块/方块实体，提供"风量"参数；炉温 = f(燃料、风量、炉型、炉衬)；风量不足 → 温度上限与还原率折减；
- **选矿**：破碎/淘洗为方块交互或简单机器；品位用 Data Component（assay）记录；
- **合金**：青铜用 `Quality.composition` 记录实际 Cu/Sn 比例（物质系统 §2.6），成分偏差影响工具耐久/硬度；
- **玻璃**：熔窑多方块（坩埚+燃烧室+风嘴）；澄清度/气泡/内应力为质量属性；退火窑独立方块；
- **显微镜**：GUI 内"调焦/放大"交互，观察结果写入研究手册；微生物条目为知识闸门；
- **发酵**：发酵罐 BlockEntity，参数（温度、氧气、接种量、时间）；杂菌为概率事件，灭菌/接种降低概率；
- **蒸馏**：蒸馏器 + 冷凝管 + 接收瓶；按温度/时间切分馏分（酒头/酒心/酒尾）；
- **数据驱动**：配方、温度、收率、杂质全部 JSON 化（与物质系统 §6 管线一致）。
