## 1. 设计定位：本阶段要教的六个"终身技能"

1. **原油评价与分馏**——API 度、硫含量、族组成；常压/减压蒸馏的馏分切割。
2. **催化裂化/重整**——沸石择形催化、流化床、积碳再生；铂重整的芳烃与氢气。
3. **蒸汽裂解与深冷**——毫秒停留、急冷、五段压缩、冷箱、C2 分离；"把石脑油拆成乙烯"。
4. **聚合**——自由基（LDPE）vs 配位（HDPE/PP）；分子量分布与熔融指数（MFR）。
5. **联产平衡**——氯平衡、氢平衡、芳烃平衡、蒸汽平衡；装置之间必须互喂。
6. **下游材料**——PVC/PS/PET/尼龙/橡胶/环氧/聚氨酯/洗涤剂；材料决定工业上限。

## 2. 开局与世界生成

### 2.1 出生点保障

阶段 6 的油气区保证：

- **油苗/沥青露头**、**背斜/盐丘构造**（钻井靶区）、**天然气**；
- **盐**（氯碱/PVC）、**石灰石/石英砂**（水泥/玻璃）、**硫磺/黄铁矿**；
- **煤**（合成气/甲醇/MTO 路线）、河流/海岸（物流/冷却）。

### 2.2 原版内容调整（本阶段生效范围）

- 原油/汽油/柴油/石脑油为流体（混合物物质，沸程档独立）；天然气为气体流体；
- 钻井、采油、管道、储罐、火炬为可建造结构；
- 车辆（轮胎解锁）与工程机械加入（物流升级），红石系保持移除；
- 塑料/橡胶制品替代部分原版材料（管道、电缆绝缘、轮胎、容器）。

### 2.3 气候与季节

- 冬季柴油凝点问题（蜡析出）；夏季汽油蒸气压（VOC）问题；
- 乙烯装置深冷能耗随环境温度上升；循环水温度影响冷凝负荷；
- 检修季（计划停车）与连续运行的矛盾。

## 3. 核心机制

### 3.1 原油评价

- API 度（轻/重）、硫含量（低硫/含硫）、族组成（烷烃/环烷烃/芳烃）；
- 实沸点蒸馏曲线（TBP）决定馏分切割方案；
- 原油"配方"影响后续装置负荷——同一套炼厂吃不同原油要调整操作。

### 3.2 常减压蒸馏

| 馏分 | 沸程 | 去向 |
|---|---|---|
| LPG | <30 °C | 燃料/化工 |
| 石脑油 | 30–180 °C | 重整/裂解原料 |
| 煤油 | 180–230 °C | 喷气燃料/照明 |
| 柴油 | 230–350 °C | 燃料 |
| 减压瓦斯油 | 350–550 °C | FCC 原料 |
| 渣油 | >550 °C | 焦化/沥青 |

- 常压塔底 ~350 °C 以上会裂解 → 必须减压蒸馏（10–50 mmHg）继续切割；
- 塔板/回流比/侧线抽出决定产品重叠度。

### 3.3 催化裂化（FCC）

- 沸石催化剂（Y 型），提升管 500–550 °C、剂油比 4–9、停留 1.5–3 s；
- 再生器 650–700 °C 烧焦（C + O₂ → CO₂），催化剂循环；
- 产品：LPG、高辛烷值汽油（RON 90–93）、轻循环油；焦炭是"代价"也是热源。

### 3.4 催化重整与加氢

- 铂重整：Pt-Re/Al₂O₃-Cl，480–530 °C、10–35 bar；产物 BTX + 高辛烷值 + 副产 H₂（2–4 wt%）；
- 加氢精制：Co-Mo/Al₂O₃，300–400 °C、30–50 bar，脱硫到 <10 ppm；H₂S → 克劳斯回收硫；
- 水氯平衡、积碳再生、催化剂寿命。

### 3.5 蒸汽裂解与深冷（本阶段 Boss）

- 石脑油 + 稀释蒸汽（蒸汽/油 0.3–0.6）→ 裂解炉 800–850 °C、停留 0.1–0.5 s → 急冷（废热锅炉）→ 五段压缩 → 碱洗 → 干燥 → 冷箱（乙烯/丙烯制冷）→ 脱甲烷/脱乙烷 → **C2 分离器** → 聚合级乙烯 99.9%；
- 联产品：丙烯、丁二烯、裂解汽油（BTX）；乙烯收率（石脑油）约 28–33%；
- 深冷温度到 −100 °C，冷箱保温/防冻/防爆是工程难点。

### 3.6 聚合

| 产品 | 工艺 | 条件 | 关键 |
|---|---|---|---|
| LDPE | 高压自由基 | 150–300 MPa、150–300 °C | 超高压容器、引发剂、转化率 15–30% |
| HDPE | Ziegler-Natta / 气相 | 60–80 °C、0.1–1 MPa | TiCl₄/AlEt₃、无水无氧、MFR |
| PP | Ziegler-Natta | 60–80 °C | 等规度 95–99%、立构规整性 |
| PVC | 悬浮聚合 VCM | 50–60 °C、0.9–1.2 MPa | 分散剂 PVA、氯平衡 |
| PS | 本体/悬浮 | 100–150 °C | 苯乙烯纯度 |
| PET | 酯化 + 缩聚 | 225–260 °C / 280–290 °C 真空 | PTA/EG、锑/钛催化、IV 0.6–0.8 |
| 尼龙 66 | 尼龙盐缩聚 | 250–280 °C | 己二酸/己二胺、HCN 剧毒链 |
| 橡胶 | 乳液/溶液聚合 | 5–50 °C | 丁苯 75/25、硫化体系、炭黑 |

### 3.7 联产平衡

- **氯平衡**：氯碱 Cl₂ → PVC（EDC→VCM，HCl 氧氯化回收）→ 必须闭环；
- **氢平衡**：重整/裂解副产 H₂ → 加氢精制/合成氨；
- **芳烃平衡**：重整 BTX → 对二甲苯（吸附分离）→ PET；甲苯歧化补缺口；
- **蒸汽平衡**：裂解炉废热 + 催化裂化余热 → 全厂蒸汽管网。

### 3.8 安全与环保

- 烃类爆炸极限（LEL/UEL）、静电、火炬系统；
- H₂S/CO/苯（致癌）暴露限值；CEMS 在线监测；
- 泄漏/溢油/地下水污染；VOC 回收；废水生化处理。

## 5. 工艺链详细设计

### 5.1 勘探、钻井与采油（8–12 h）

地质构造（背斜/盐丘）→ 钻机（旋转钻、钻井液、套管）→ 试油 → 自喷/抽油机 → 注水（EOR）→ 集输/储罐；伴生气分离（天然气/液化气）。

### 5.2 常减压蒸馏（8–10 h）

原油脱盐/脱水 → 加热炉（350–400 °C）→ 常压塔（侧线：石脑油/煤油/柴油）→ 减压塔（VGO/渣油）；回流比/塔板/侧线抽出控制；产品重叠度检测（馏程/密度）。

### 5.3 催化裂化（8–10 h）

VGO + 再生催化剂 → 提升管 500–550 °C → 旋风分离 → 分馏（LPG/汽油/柴油）→ 催化剂再生（烧焦 650–700 °C）→ 循环；汽油辛烷值/烯烃含量；烟气余热回收。

### 5.4 重整、加氢与硫回收（8–10 h）

石脑油预加氢 → 铂重整（480–530 °C、10–35 bar）→ BTX 抽提 → 高辛烷值组分；柴油加氢精制（Co-Mo）→ H₂S → 克劳斯（2H₂S + SO₂ → 3S + 2H₂O，200–300 °C）→ 硫磺；尾气加氢/焚烧。

### 5.5 蒸汽裂解 + 深冷（12–16 h，本阶段 Boss）

石脑油 + 蒸汽 → 裂解炉 800–850 °C/0.1–0.5 s → 急冷 → 五段压缩 → 碱洗 → 分子筛干燥 → 冷箱（−100 °C）→ 脱甲烷/脱乙烷 → C2 分离 → 乙烯 99.9%；丙烯/C4/裂解汽油分别精制；乙烯装置"三机"（裂解气、丙烯、乙烯压缩机）是能耗大头。

### 5.6 PE/PP（6–8 h）

LDPE：乙烯 + 引发剂 → 150–300 MPa/150–300 °C → 高压分离/造粒；HDPE/LLDPE：TiCl₄/AlEt₃（或气相流化床）→ 60–80 °C；PP：丙烯 + ZN 催化剂 → 等规 PP；MFR/密度/等规度检测。

### 5.7 PVC（6–8 h）

乙烯 + Cl₂ → EDC → 裂解 500–550 °C → VCM + HCl；HCl 氧氯化回收 → EDC；VCM 悬浮聚合（50–60 °C、PVA 分散剂）→ PVC 粉料 → 管材/型材/电缆料（增塑剂 DOP）。

### 5.8 PS/ABS（4–6 h）

乙苯（苯 + 乙烯，分子筛烷基化）→ 脱氢 → 苯乙烯 → 本体/悬浮聚合 → PS；ABS = 丙烯腈（丙烯氨氧化）+ 丁二烯 + 苯乙烯接枝。

### 5.9 PET（8–10 h）

对二甲苯（重整/异构化/甲苯歧化）→ 吸附分离（模拟移动床）→ PTA 氧化（Co-Mn-Br/醋酸，钛材防腐）→ 与乙二醇（环氧乙烷水解）酯化 → 缩聚（280–290 °C、真空）→ PET 切片 → 熔纺 → 涤纶；IV 检测。

### 5.10 尼龙 66（8–10 h）

苯 → 环己烷 → 环己醇/酮（KA 油）→ 己二酸（硝酸氧化）；丁二烯 + HCN → 己二腈 → 己二胺（雷尼镍加氢）；尼龙盐 → 缩聚（250–280 °C）→ 纺丝/工程塑料；HCN 剧毒链全封闭。

### 5.11 合成橡胶（6–8 h）

丁苯 SBR（丁二烯/苯乙烯 75/25，乳液 5–50 °C）→ 凝聚/干燥；顺丁 BR（溶液聚合，丁基锂/钴系）；轮胎：炭黑（炉法 1200–1500 °C）+ 钢丝帘线 + 硫化（硫磺/促进剂 MBT）→ 轮胎（车辆解锁）。

### 5.12 环氧/聚氨酯/LAS（8–10 h）

双酚 A（苯酚 + 丙酮）→ 环氧树脂（环氧氯丙烷）；MDI/TDI（光气 + 苯胺/甲苯二胺，全封闭）；LAS（正构烷烃 → 烷基苯 → SO₃ 磺化 → 中和）；HPPO 法环氧丙烷（H₂O₂ + TS-1）绿色路线可选。

### 5.13 合成气平台（8–10 h）

天然气蒸汽重整（SMR，Ni 催化 800–900 °C）或煤气化（O₂/水蒸气）→ 合成气 → 甲醇（Cu/ZnO/Al₂O₃，250–300 °C、50–100 bar）→ 甲醛/乙酸（Rh 羰基化，150–200 °C、30–60 bar）/MTO（SAPO-34，400–500 °C）；煤化工 vs 石油化工双路线分支。

## 7. 里程碑与阶段出口

**十项必需（研究手册逐条记录）：**

1. **常减压蒸馏**：石脑油/煤油/柴油/VGO/渣油切割，馏程达标；
2. **FCC**：提升管+再生器稳定运行，汽油辛烷值达标；
3. **重整 + 加氢 + 硫回收**：BTX、低硫柴油、硫磺闭环；
4. **蒸汽裂解 + 深冷**：聚合级乙烯 99.9%（**总门槛**）；
5. **PE/PP**：LDPE 与 HDPE 各一批，MFR 达标；
6. **PVC**：氯平衡闭环（HCl 氧氯化回收）；
7. **PS/ABS**：苯乙烯/丙烯腈链打通；
8. **PET**：从原油到涤纶丝（"从石油到布料"）；
9. **尼龙 66**：HCN 剧毒链安全达标；
10. **合成气平台 + 橡胶/环氧/PU/LAS**：甲醇/乙酸各一批，轮胎下线。

**出口任务「精细的召唤」**：用自产苯/甲苯产出 ≥99.5% 的纯苯，并做出苯酚或苯胺；研究手册解锁阶段 7："分子设计，从这里开始。"

## 10. 实现要点（技术）

- **原油**：用组分表（烷烃/环烷/芳烃/硫）描述，馏程曲线驱动切割；
- **蒸馏塔**：理论塔板 + 回流比 + 侧线抽出；产品重叠度；真空系统；
- **FCC**：提升管反应-再生耦合（焦炭燃烧供热）、催化剂活性衰减；
- **裂解炉**：停留时间/温度/蒸汽比 → 产品分布（收率模型）；结焦；
- **深冷**：多级压缩 + 制冷循环（乙烯/丙烯/甲烷）；冷箱换热网络；
- **聚合**：分子量分布/MFR；配位聚合需无水无氧（惰性气氛）；
- **联产平衡**：全厂物料衡算面板（Cl/H₂/BTX/蒸汽），装置间调度；
- **安全环保**：LEL 检测、火炬、CEMS、废水生化；
- **数据驱动**：馏分切割点、催化条件、聚合配方 JSON 化。
